돈이 드는 자리와 안 드는 자리

영상과 음악은 만들 때마다 반드시 과금된다. 이미지와 목소리는 애플 실리콘 맥에서 기기 안 엔진으로 공짜로 만들 수 있고, 받아쓰기는 아예 무료 경로뿐이다.

다만 무료 경로에는 각각 못 하는 일이 있다. 그 한계가 곧 "이건 돈을 내야 한다"의 목록이다.

기본 파이프라인은 영상 생성을 한 번도 부르지 않는다. 정지 이미지 몇 장에 ffmpeg 켄번즈를 얹고 나레이션·자막·배경음악을 붙이는 구성이라, 영상 생성은 사람이나 지표가 따로 올려 줄 때만 쓴다. 그래서 실제 한 편 값은 대개 커버 이미지 한 장 + 배경음악 한 클립이 전부다 — 8장에서 계산해 본다.

이 문서에 적힌 단가는 전부 skills/autoproduce/references/prices.tsv 한 파일에서 왔다. 각 줄에는 근거 등급이 붙어 있고, 이 문서도 그 등급을 그대로 옮긴다.

  • official 벤더 요금 페이지를 직접 열어 확인한 값
  • derived 공식 값에서 계산한 값 — 해상도 비율을 곱했거나 예시 가격을 초로 나눴다
  • unconfirmed 벤더가 공개하지 않은 값. ? 로 적혀 있고 집계기가 이 줄을 만나면 판정을 거부한다

이미지

무료 — image_local_generate

Z-Image Turbo 를 mflux/MLX 로 기기 안에서 돌린다. 키도 네트워크도 과금도 없고 전기만 든다.

  • 애플 실리콘 전용
  • uv tool install --python 3.12 mflux
  • 첫 호출 때 가중치 약 31GB 다운로드
  • 9:16 은 1088×1920 (가로세로가 16 의 배수여야 한다)

유료 — gpt_image_text2img · img2img

OpenAI GPT Image. 장당 과금이고 품질 등급에 따라 값이 크게 다르다.

  • OPENAI_API_KEY 필요
  • 그림 안 글자를 제대로 그린다
  • 가로세로 자유·레퍼런스 이미지 최대 16장·마스크 인페인팅

로컬 엔진의 벽 — 그림 안 글자

로컬 엔진으로는 글자가 들어간 그림을 만들지 못한다. 한글을 넣으면 자소가 흩어지고 비슷하게 생긴 다른 글자로 바뀐다. 실측으로 "딸깍연구소"가 "달닥연구소"로 나왔다.

그래서 커버와 글자가 들어가는 프레임은 유료 경로로 고정돼 있다. 씬 배경처럼 글자가 없는 그림은 전부 로컬이 기본 경로다.

로컬 생성도 원장에는 image.local 로 적는다. 값이 0 이라 합계는 안 움직이지만, 원장에 없는 키를 만나면 집계기가 종료 코드 1 로 멈춰 그 회차 정산이 통째로 막힌다.

mflux 를 안 깐 기계에서는 씬 배경이 gpt_image_text2img 품질 low 로 떨어진다. 장당 $0.007 이라 큰돈은 아니지만 2~4장이면 한 편에 $0.014~0.028 이 붙는다 — 8장의 상한 계산에 이 값이 들어간다.

영상

생성 영상에는 무료 경로가 없다. 기기 안에서 도는 영상 엔진은 이 플러그인에 없고, 두 엔진 모두 초 단위로 과금한다.

그래도 기본값은 영상 호출 0 회다. 자동 저작의 경제 티어는 정지 이미지 + 켄번즈로 60초를 채운다. Veo 는 한 번에 최대 8초라 생성 영상만으로 한 편을 채우려면 여덟 컷을 뽑아 이어 붙여야 하고, 어차피 편집 레이어가 필요하다. 그래서 남는 질문은 하나다 — 어느 한 칸에 생성 영상을 넣을 것인가.

Veo 3.1 — 초당 과금, 소리 포함, 길이는 4·6·8초 격자

Veo 는 GEMINI_API_KEY 로 부르고 소리가 항상 포함된다. 끌 수 없고 무료 구간도 없다. 길이는 4·6·8초 격자에 고정돼 있으며 1080p 와 4K 는 8초짜리만 만들어진다.

4초만 쓸 거라도 8초 값을 낸다. 1080p 를 4초만 생성하는 선택지가 API 에 없기 때문이다. 초당 단가만 비교하면 실제 지출을 과소평가한다 — 원장에는 생성 길이를 적는다.

Seedance — 요청한 초만큼만, 소리는 선택

Seedance 줄이 전부 derived 인 이유는 벤더가 토큰으로 청구하기 때문이다. 공식 문서의 "5초·16:9" 예시 가격을 5 로 나눈 값이고, 9:16 은 가로세로만 바뀌어 토큰 수가 같아서 같은 값을 쓴다. 실제 청구의 정본은 응답의 completion_tokens 이므로 회차 원장의 메모 칸에 그 값을 적어 둔다. 한시 할인은 단가에 반영하지 않았다 — 반영해 두면 행사가 끝나는 날 조용히 틀린 값이 된다.

Seedance 2.x 는 키 하나로 열리지 않는다. Dreamina Seedance 2.5·2.0 계열은 계정 잔액 $30 이상이거나 리소스 팩을 구매해야 활성화된다. 1.5 pro 와 1.0 계열에는 이 관문이 없다. 그와 별개로 모든 모델은 콘솔의 Model activation 에서 한 번 켜 줘야 하고, 안 켜면 작업 생성이 ModelNotOpen 으로 실패한다.

승급 한 칸 — 언제 영상에 돈을 쓰나

자율 루프가 스스로 올릴 수 있는 자리는 커버 다음 세그먼트의 도입 b-roll 한 칸뿐이다. 스키마상 두 칸까지 가능하지만 두 칸째는 사람이 스토리보드를 승인하면서 결정한다. 커버 자체는 승급하지 않는다 — Veo 가 한글을 못 써서 훅 제목은 코드로 그리기 때문이다.

승급 판정은 절대 문턱이 아니라 추세다. 문턱으로 잡으면 측정값이 늘 그 위에 있는 채널은 매 편 승급 = 매 편 5배 지출이 되는데, 그 돈이 문제를 고치지도 못한다. b-roll 은 커버 뒤에 붙고 이탈은 커버 안에서 일어나기 때문이다.

훅 계약을 고친 직후에도 승급을 동결한다. 훅이 바뀌면 그전 회차의 지표는 비교 대상이 아니라서, 새 기준 3편이 쌓일 때까지 경제 티어로만 만든다.

목소리(TTS)

무료 — tts_local_generate

Supertonic 3 을 기기 안에서 돌린다. 키도 네트워크도 없다. CPU 만으로 실시간의 6.3배 속도가 실측값이다.

  • pip install supertonic
  • 첫 호출 때 가중치 385MB → ~/.cache/supertonic3 (24초쯤)
  • 목소리 10종 · 언어 31종 · 모노 44.1kHz
  • 가상환경에 깔았으면 SUPERTONIC_PYTHON

유료 — tts_generate · tts_multi_speaker

Gemini TTS. 1,000자 단위로 값을 매긴다.

  • GEMINI_API_KEY 필요
  • 연기·감정 지시를 받는다 (stylePrompt)
  • 목소리 30종 · 2인 대화 · 모노 24kHz

라이선스 — 상업 채널이라면 읽고 넘어간다

Supertonic 은 코드가 MIT, 가중치가 OpenRAIL-M 이다. 상업적 사용은 허용되지만 용도 기반 제한(use-based restrictions)이 붙어 있어서, 라이선스가 금지한 용도로는 쓰지 못하고 재배포할 때 같은 제한을 그대로 물려줘야 한다. 광고가 붙는 채널을 운영할 거라면 원문 라이선스를 한 번 읽어 두는 편이 안전하다.

Gemini 는 사실 글자가 아니라 오디오 토큰(초당 25개)으로 청구한다. 위 값은 100만 자를 한국어 실측 발화 속도 6.55자/초로 환산해 1,000자당 값으로 되돌린 것이라 derived 다.

한 영상 안에서 두 엔진을 섞으면 표본율이 어긋난다. 로컬은 44.1kHz, Gemini 는 24kHz 라서 그냥 이어 붙이면 접합이 깨진다. 섞어야 한다면 리샘플링을 거쳐야 하고, 자동 저작 경로는 이 문제 때문에 아예 한 엔진으로만 만든다.
운영 중인 채널의 엔진을 바꾸지 않는다. "로컬이 공짜니까" 하고 gemini 채널을 로컬로 옮기면 중간부터 나레이터가 다른 사람이 된다. 엔진은 사용자가 profile.md §2 를 직접 고칠 때만 바뀐다 — 자동 저작에는 이걸 금지하는 절대 규칙이 따로 있다.

그래서 역할 분담이 이렇다. 나레이션 본문은 로컬, 연기가 필요한 컷만 Gemini. 인트로 대사나 캐릭터 대사처럼 감정 지시가 필요한 자리에만 유료 엔진을 쓴다.

받아쓰기(STT)

받아쓰기는 무료 경로뿐이다. 이 플러그인에 유료 STT 는 없다. 화면 녹화를 소재로 쓰는 ingest 스킬이 whisper.cpp 를 기기 안에서 돌린다.

돈은 안 들지만 준비물이 둘 있다.

  • whisper.cpp 본체 — brew install whisper-cpp
  • 모델 파일 — ggml-large-v3-turbo.bin(1.5GB)을 huggingface.co/ggerganov/whisper.cpp 에서 받아 ~/.cache/whisper-cpp/ 에 둔다. 다른 자리에 뒀으면 WHISPER_MODEL 로 경로를 지정한다.

녹화까지 하려면 터미널 앱에 화면 기록·마이크 권한이 있어야 한다(시스템 설정 → 개인정보 보호 및 보안). 권한이 없으면 녹화 단계에서 멈춘다.

동작을 조절하는 환경변수는 skills/ingest/references/transcribe.sh 머리에 정리돼 있다 — 언어(WHISPER_LANG, 기본 ko), 용어집 주입(WHISPER_PROMPT), 무음 판정 레벨(SIL_DB), 화면 전환 감도(SCENE_THRESH).

이건 고장이 아니라 의도된 동작이다. 모르는 값을 0 으로 적으면 회차 비용이 조용히 줄어든다. 집계기는 나머지 항목의 합계는 그대로 찍어 주므로, 보고는 "합계 $X + 집계 제외 1건(BGM)" 형태로 쓴다. 0 으로 적지도, 줄을 지우지도 않는다.

조사 단계가 쓰는 건 돈이 아니라 호출 쿼터다. 다 쓰면 그날 조사가 막히므로 단가만큼 아껴 쓴다.

유료 키를 하나도 넣지 않아도 파이프라인은 돈다. 무엇이 되고 무엇이 안 되는지 정직하게 적으면 이렇다.

실제로 아픈 손실은 배경음악과 커버 품질 둘이다. 생성 영상은 기본 파이프라인이 애초에 안 부르니까 없어도 결과물이 크게 달라지지 않지만, 배경음악이 빠진 쇼트폼은 소리가 허전하고 커버는 그 자체로 썸네일이라 훅을 못 걸면 스크롤로 넘어간다.

중간 단계도 있다. OPENAI_API_KEY 하나만 넣으면 커버가 살아나고 한 편 값이 $0.22 다. 거기에 GEMINI_API_KEY 를 더하면 배경음악까지 붙어 $0.26 이 된다. 두 키가 경제 티어의 전부다.

키 발급 — 하나씩

키는 셸 환경변수로 넣는다. .mcp.json 이 셸 환경을 서버로 그대로 넘겨주므로 커밋되는 파일 어디에도 키 값이 들어가지 않는다. 변수 목록과 주석은 저장소 루트의 .env.example 에 있다.

# .env.example 을 복사해 쓰는 방법
cp .env.example .env
$EDITOR .env
set -a && . ./.env && set +a

~/.zshrc 에 export 로 적어 두는 방법도 같다. 어느 쪽이든 세션은 띄울 때의 환경변수를 그대로 들고 간다 — 키를 새로 넣었으면 claude 를 다시 띄워야 반영된다.

OPENAI_API_KEY 제작

platform.openai.com/api-keys

여는 것 — gpt_image_text2img · gpt_image_img2img. 커버와 글자 들어간 프레임.

export OPENAI_API_KEY="sk-..."

확인 — 모델 목록 조회는 과금이 붙지 않는다.

curl -s https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | head -c 200

키만으로는 부족하다. 계정에 크레딧이 없으면 이미지 생성이 실패한다 — OpenAI 대시보드의 Billing 에서 결제 수단을 걸고 크레딧을 채워 둔다. 위 조회가 401·403 으로 돌아오면 키 값이 틀렸거나 결제가 안 걸린 것이다.

GEMINI_API_KEY 제작

aistudio.google.com/apikey · GOOGLE_API_KEY 로 적어도 같다

여는 것 — veo_*(생성 영상) · tts_generate·tts_multi_speaker(연기 목소리) · music_*(배경음악). 셋이 이 키 하나를 같이 쓴다.

export GEMINI_API_KEY="..."

확인

curl -s "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY" | head -c 200

모델 목록이 JSON 으로 돌아오면 된 것이다. 401·403 이면 키 값이 틀렸거나 결제가 안 걸려 있다.

여는 것 — seedance_*, 두 번째 영상 엔진. 이 키가 없어도 Veo 는 GEMINI_API_KEY 로 그대로 돈다.

# 리전 엔드포인트는 건드리지 않는다 — 영상 모델은 ap-southeast-1 에만 있다
# export ARK_BASE_URL=https://ark.ap-southeast.bytepluses.com/api/v3

관문이 세 개다. 순서대로 넘어야 호출이 된다.

확인 — 읽기 전용 점검 엔드포인트가 없어서, 키를 빼먹으면 도구가 위 세 가지를 구분해 알려 주는 오류 메시지에 기대는 편이 낫다. 실제 생성 호출은 곧 과금이다.

플랫폼 토큰은 키가 아니라 파일이다. 스레드·인스타그램·페이스북·유튜브 자격증명은 환경변수가 아니라 ~/.config/social-flow/<채널slug>/ 아래 파일로 둔다(chmod 600). 발급 절차는 시작하기 가이드와 skills/publish/references/token-setup.md 에 있다. 게시·성장 루프를 안 쓸 거라면 통째로 건너뛰어도 된다.

온디바이스 엔진 설치

공짜 경로 셋은 각각 한 번씩 설치한다. 셋 다 첫 호출에서 가중치를 내려받으므로 처음 한 번은 오래 걸린다는 것만 알고 시작한다.

mflux — 로컬 이미지 생성

image_local_generate · Z-Image Turbo

전제 — 애플 실리콘 맥 전용이다(MLX 기반). 인텔 맥이나 리눅스에서는 이 경로가 없으므로 이미지는 gpt_image_text2img 로 간다.

uv tool install --python 3.12 mflux

첫 호출 — 가중치 저장소 약 31GB 를 ~/.cache/huggingface 로 내려받는다. 서버는 첫 호출을 알아채고 다운로드용 여유 시간을 따로 얹으므로, 오래 걸려도 중간에 끊기지 않는다.

확인 — 설치 경로에 실행 파일이 있는지 본다.

ls ~/.local/bin/mflux-generate-z-image-turbo

다른 자리에 깔았으면 MFLUX_ZIMAGE_BIN 에 실행 파일 경로를 적는다. PATH 를 뒤지는 자동 탐색은 일부러 넣지 않았다 — 조용히 다른 환경을 집어 어제와 다른 결과를 내는 사고를 막으려고 그렇다.

export MFLUX_ZIMAGE_BIN=~/.venvs/mflux/bin/mflux-generate-z-image-turbo

M4 Max 실측으로 9스텝 기준 1024×1024 가 116~197초, 1088×1920 이 443초다. 최대 메모리는 32~39GB 를 쓴다.

Supertonic — 로컬 TTS

tts_local_generate · Supertonic 3

전제 — 파이썬 런타임.

pip install supertonic

첫 호출 — 가중치 385MB 를 ~/.cache/supertonic3 로 내려받는다. 24초쯤 걸린다.

가상환경에 깔았으면 SUPERTONIC_PYTHON 에 그 인터프리터 경로를 적는다. 여기도 자동 탐색이 없다 — 저장소마다 다른 venv 를 집으면 목소리가 바뀐다.

export SUPERTONIC_PYTHON=~/.venvs/tts/bin/python

확인

$SUPERTONIC_PYTHON -c "from supertonic import TTS; print('ok')"

패키지가 없으면 도구를 부를 때 설치 안내가 담긴 오류가 돌아온다. 라이선스는 4장에 적어 뒀다 — 코드 MIT, 가중치 OpenRAIL-M.

whisper.cpp — 로컬 STT

ingest 스킬의 받아쓰기
brew install whisper-cpp

모델 — huggingface.co/ggerganov/whisper.cpp 에서 ggml-large-v3-turbo.bin(1.5GB)을 받아 ~/.cache/whisper-cpp/ 에 둔다.

확인 — 이 두 줄이 다 통과해야 ingest 가 시작된다.

command -v whisper-cli
ls ~/.cache/whisper-cpp/ggml-large-v3-turbo.bin

모델을 다른 자리에 뒀으면 WHISPER_MODEL 로 경로를 지정한다.

export WHISPER_MODEL=~/models/ggml-large-v3-turbo.bin

녹화까지 하려면 터미널 앱에 화면 기록·마이크 권한이 있어야 한다.

비용을 실제로 통제하는 법

예상과 실제는 다른 파일에 적는다

파일무엇을 적나언제 쓰나
.work/cost-estimate.tsv쓰기 전 예상치상한 판정 — 승급을 결정하는 순간
.work/cost-tally.tsv실제로 쓴 내역회차 정산 — 스토리보드와 제작이 번갈아 적는다

두 파일을 섞지 않는다. 한 파일에 합치면 사후 정산이 같은 지출을 두 번 센다. 반대로 중간 재판정도 예상 파일로 한다 — 재생성을 결정할 때 그 줄을 예상 파일에 얹고 상한을 다시 돌린다. 실제 원장으로 판정하면 아직 안 나간 지출(배경음악·나레이션)이 빠져 있어서 합계가 작게 보이고, 상한을 넘길 재생성이 통과한다.

원장 한 줄은 탭으로 나눈 세 칸이다.

image.gpt-image-2.high	1	storyboard: 커버 배경 scene-1
image.local	3	storyboard: 포인트 배경 scene-2~4
veo.lite.1080p	8	produce: b-roll a1 — 8초 생성, 4초 사용
tts.local	0.412	produce: 나레이션 412자
music.lyria-clip	1	produce: BGM 30초

수량은 개수가 아니라 그 단위의 양이다. TTS 는 글자 수 ÷ 1000, Veo 는 생성 길이(쓴 길이가 아니다), Seedance 는 요청한 초 그대로. 버린 것도 적는다 — 검토 뒤 다시 만든 이미지, 마음에 안 들어 다시 뽑은 컷, 길이 검사에 걸려 다시 돌린 TTS 는 결과물에 없어도 청구서에는 있다.

집계기 — 종료 코드를 곧이곧대로 읽는다

REF=${CLAUDE_PLUGIN_ROOT}/skills/autoproduce/references
$REF/cost-report.sh .work/cost-estimate.tsv --cap 0.30; echo "cost_exit=$?"
종료 코드뜻할 일
0정상 (상한을 줬으면 그 안)합계가 그 회차 비용이다
1판정 불가!! 줄을 보고서에 그대로 옮긴다
2상한 초과승급을 취소하고 경제 티어로 돌아간다
3입력 오류경로·형식을 고치고 다시 돌린다
1 을 통과로 읽지 않는다. 모르는 키나 미확인 단가(?)를 만나면 합계가 0 처럼 보일 수 있다. 그건 공짜라는 뜻이 아니라 계산이 안 됐다는 뜻이다.

1 의 원인은 두 가지고 대응이 다르다. !! unknown key 는 우리 실수이므로 키 이름을 prices.tsv 에 맞추고 다시 돌린다. !! price unconfirmed 는 벤더가 값을 공개하지 않은 항목이고, 지금은 music.lyria-realtime 하나다 — 이때는 "합계 $X + 집계 제외 1건(BGM)" 으로 보고한다.

합계 $0 을 그대로 보고하지 않는다. storyboard/images/*.png 가 있는데 원장이 비어 있으면 공짜로 만들어진 게 아니라 기록을 건너뛴 것이다. 파일 수를 세어 원장을 채우고 보고에 그 사실을 적는다.

하루·주 단위 상한

상한 값 셋은 성장 플랜의 autoproduce: 블록에 있다.

설정기본값무엇을 막나
max_cost_per_video$0.30회차 하나 — 경제 티어만 통과, Veo 승급은 차단
daily_cost_cap$0.60하루 채널 전체 누적
weekly_cap$2.00한 주 채널 전체 누적

누적 실적은 data/<채널>/growth/autoproduce.json 에 쌓이고, 성장 루프가 저작을 시작하기 전에 이 파일을 읽어 위 상한과 대조한다. 편수는 호출자(플랜)별, 돈은 채널 전체로 센다 — 편수 상한은 플랫폼마다 따로 두는 게 맞지만 돈은 어느 루프가 썼든 같은 지갑에서 나가기 때문이다. 편수는 그와 별개로 플랫폼 루프당 하루 2편이 절대 상한이고, 성공과 실패를 함께 센다.

단가가 바뀌면

고칠 파일은 skills/autoproduce/references/prices.tsv 하나다. 집계기는 이 파일만 읽고, 설명 문서는 숫자를 옮겨 적지 않는다 — 같은 값을 두 군데 적으면 한쪽은 반드시 낡는다.

  • 근거 등급(official / derived / unverified)과 출처를 같은 줄에 남겨 둔다.
  • 확인 못 한 값은 ? 로 둔다. ? 는 정산을 실패시켜 사람을 부른다 — 지어낸 숫자를 채워 넣으면 상한이 조용히 풀린다.
  • 벤더 가격은 바뀐다. 분기마다 출처를 다시 열어 본다.
