GETTING STARTED

설치부터 첫 영상까지

social-flow 는 주제 하나를 받아 쇼트폼 영상과 SNS 글을 만들고, 사람이 승인하면 계정에 올려 주는 Claude Code 플러그인이다. 설치는 5분, 첫 영상은 명령 네 줄이면 나온다.

무엇을 하는 도구인가

영상 한 편을 올리려면 보통 이런 일을 한다. 자료를 찾고, 대본을 쓰고, 그림을 구하고, 목소리를 입히고, 자막을 달고, 플랫폼마다 다른 글을 따로 쓴다. social-flow 는 이 과정을 네 단계 명령으로 묶어 놓은 도구다.

STEP 1 채널 누구에게 어떤 말투로 말할지 한 번 정한다
STEP 2 스토리보드 자료를 찾아 대본과 씬 그림을 만든다
STEP 3 제작 세로 영상 + 플랫폼별 글을 뽑는다
STEP 4 게시 사람이 확인하고 승인하면 올린다

앞 단계가 끝나야 다음 단계가 돈다. 순서를 건너뛰면 그 자리에서 멈추고 무엇이 빠졌는지 알려 준다.

알아 두면 좋은 세 가지

  • 영상은 9:16 세로 한 가지로 만든다. 1080×1920 · 30fps 한 벌을 만들어 릴스·쇼츠·스레드로 각각 내보낸다.
  • 같은 글을 여러 곳에 복붙하지 않는다. 사실은 하나를 쓰되 문장은 플랫폼마다 다시 쓴다. 스레드는 반말 구어체, 유튜브는 검색되는 제목·설명처럼 성격이 다르기 때문이다.
  • 기본 흐름에는 사람 승인이 두 번 있다. 스토리보드를 확정할 때와 실제로 올리기 직전이다. 예외는 성장 루프 하나다 — 계정을 스스로 키우는 grow-* 스킬은 처음 한 번 승인받은 성장 계획이 게시별 승인을 대신한다. 그 범위 안에서는 묻지 않고 올리므로 계획을 승인할 때 범위를 좁게 잡는 편이 좋다.

준비물

맥이나 리눅스 터미널, 그리고 Claude Code 가 이미 깔려 있다고 보고 시작한다.

필요한 것확인·설치왜 필요한가
Node 20 이상 필수node -v플러그인 안에서 도는 서버가 Node 로 만들어져 있다
ffmpeg 필수brew install ffmpeg영상·소리를 자르고 붙인다. 없으면 3단계에서 멈춘다
python3 필수python3 -V한국어 문장을 검사하는 스크립트가 파이썬이다
Google Chrome 필수이미 깔려 있으면 그대로영상 화면을 웹 페이지로 그린 뒤 캡처한다
whisper.cpp 선택brew install whisper-cpp화면 녹화를 받아쓰기할 때만 쓴다
맥이 아니어도 되나? 영상 제작까지는 리눅스에서도 돈다. 다만 화면 녹화 기능과 온디바이스 이미지 생성은 macOS·Apple Silicon 전용이다.
API 키 없이 공짜 경로로 갈 생각이라면 미리 준비할 게 더 있다. 뒤에 나오는 로컬 대안 둘은 따로 깔아야 한다 — 이미지는 uv tool install --python 3.12 mflux 를 깔고 첫 호출 때 가중치 31GB 를 내려받는다. 목소리는 pip install supertonic 이면 되고, 파이썬을 여러 개 쓰면 SUPERTONIC_PYTHON 으로 어느 것을 쓸지 지정한다.

설치

1

내려받고 서버를 빌드한다

이 한 단계를 빼먹으면 플러그인은 붙어도 도구가 하나도 안 보인다. 저장소에는 빌드 결과까지 들어 있지만 실행에 필요한 라이브러리(node_modules)는 들어 있지 않기 때문이다.

git clone https://github.com/zeanxai/social-flow.git
cd social-flow/server
npm install && npm run build

npm run check 로 바꿔 실행하면 빌드와 함께 자체 점검 테스트도 돈다. 외부 API 를 부르지 않아 키가 없어도 통과한다.

이 저장소는 비공개다. 접근 권한이 있는 GitHub 계정으로 인증해야 git clone 이 된다. 권한이 없으면 "권한 없음"이 아니라 Repository not found 가 떠서 원인을 짚기 어렵다. 이미 내려받은 폴더가 있으면 그걸 그대로 쓰면 된다.
2

작업할 폴더를 정하고 그 안에서 Claude Code 를 띄운다

만들어진 영상·대본은 data/ 폴더에 쌓이는데 이 폴더는 Claude Code 를 띄운 위치에 생긴다. 플러그인을 내려받은 곳이 아니다. 그래서 작업 폴더를 하나 정해 두고 늘 거기서 시작하는 편이 낫다.

# 예: 홈 아래에 작업 폴더 하나
mkdir -p ~/social-work && cd ~/social-work
claude
3

플러그인을 등록한다

Claude Code 안에서 두 줄을 친다. 앞 줄의 경로는 1단계에서 내려받은 폴더다.

/plugin marketplace add ~/social-flow
/plugin install social-flow@social-flow-local

매번 등록하지 않고 그때그때 켜서 쓰고 싶으면 이 방법도 된다.

claude --plugin-dir ~/social-flow
4

제대로 붙었는지 본다

/mcp 를 치면 연결된 서버 목록이 나온다. social-flow 가 있고 도구 목록이 보이면 끝났다.

도구 개수가 29개쯤이어도 정상이다. 전체 38종 가운데 게시·인사이트 툴 9종은 그 계정의 자격증명 파일이 있는 플랫폼만 나타난다. 아직 계정을 연결하지 않았다면 안 보이는 게 맞다.

API 키 넣기

키는 파일이 아니라 셸 환경변수로 넣는다. ~/.zshrc(또는 ~/.bashrc)에 적고 터미널을 새로 열면 된다.

export OPENAI_API_KEY="sk-..."     # 씬 그림
export GEMINI_API_KEY="..."        # 영상·목소리·배경음악

첫 영상을 만드는 데 실제로 필요한 건 이 둘이다. 나머지는 있으면 조사 품질이 올라가는 정도다.

키발급처없으면 무슨 일이 생기나
OPENAI_API_KEY
첫 영상에 필요		 platform.openai.com/api-keys 스토리보드의 씬 그림을 못 만든다. 애플 실리콘 맥이라면 온디바이스 생성(image_local_generate)으로 대신할 수 있다 — 공짜지만 그림에 글자를 넣지는 못한다
GEMINI_API_KEY
첫 영상에 필요		 aistudio.google.com/apikey 내레이션 목소리·배경음악·생성 영상이 전부 막힌다. 목소리만은 로컬 엔진(tts_local_generate)으로 대신할 수 있다
NAVER_CLIENT_ID
NAVER_CLIENT_SECRET
선택		 developers.naver.com 한국어 자료 조사가 일반 웹 검색으로만 돈다. 하루 25,000회까지 무료라 국내 주제를 다룬다면 넣는 편이 좋다
SERPAPI_API_KEY
선택		 serpapi.com 정밀 검색·해외 자료 조사를 건너뛴다 (월 250회 무료)
DATA_GO_KR_API_KEY
선택		 data.go.kr 마이페이지 공공데이터 API 호출만 막힌다. 데이터셋 검색·파일 내려받기는 키 없이도 된다
키를 설정 파일에 적지 않는다. .mcp.json 은 셸 환경변수를 그대로 넘겨줄 뿐이라, 저장소 어디에도 키 값이 들어가지 않는다. 키가 없는 도구는 부르는 순간 "키가 없다"고 분명히 알려 주고, 나머지 기능은 그대로 돈다.

첫 영상 만들어 보기

재테크 채널로 환율 영상 한 편을 만든다고 하자. Claude Code 안에서 명령을 차례로 친다.

1

채널을 만든다 — 채널당 한 번

/social-flow:channel add 재테크

맨 먼저 채널명을 영문 slug 로 바꿔 제안한다 — "재테크"라면 money 같은 것이다. 폴더 이름과 게시 계정 키로 쓰이는 값이라 한글을 쓰지 않는다. 이 다음부터 명령에 넣는 채널은 원래 이름이 아니라 이 slug 다.

이어서 누가 보는지, 어떤 말투로 말할지, 어디에 올릴지를 몇 가지 물어본 뒤 data/money/profile.md 에 적어 둔다. 이후 모든 작업이 이 파일을 먼저 읽어 톤과 목소리를 이어받는다.

내레이션 목소리도 여기서 하나 정해 고정한다. 회차마다 목소리가 바뀌면 같은 채널로 안 들리기 때문이다.

2

스토리보드를 만든다 — 가장 오래 걸리는 단계

/social-flow:storyboard money "7월 환율 변동"

자료를 찾고, 씬을 나누고, 대사를 쓰고, 씬마다 세로 그림을 만든다. 결과는 브라우저로 열어 볼 수 있는 storyboard.html 로 나온다.

사람에게 보여 주기 전에 검토용 에이전트가 원고와 그림을 네 번 다시 본다 — 문장이 AI 가 쓴 티가 나는지, 씬 하나하나가 제 역할을 하는지, 낱말이 사람이 쓰는 말인지, 그림이 그 씬 내용과 맞는지. 기준에 못 미치면 스스로 고쳐 다시 본다. 여기서 시간이 걸리는 건 정상이다. 마지막에 확인 요청이 오면 승인한다.

3

영상과 글을 뽑는다

/social-flow:produce money 20260729-환율

주제 이름은 2단계가 만든 폴더 이름을 그대로 쓴다. 화면을 그려 캡처하고, 목소리를 입히고, 배경음악을 깔고, 자막을 붙여 세로 영상을 만든다. 여기에 스레드·인스타·페이스북·유튜브용 글이 각각 따로 나온다.

결과물은 data/money/20260729-환율/output/ 에 있다. 자막을 화면에 태운 영상과 태우지 않은 영상이 따로 나오는데 인스타는 자막 파일을 못 받아 태운 쪽을 쓰고 유튜브·페이스북은 자막을 따로 올린다.

4

올린다

/social-flow:publish money 20260729-환율

플랫폼별 최종 문안과 올라갈 계정을 전부 보여 주고 승인을 받는다. 승인해야 실제 호출이 나가고 올라간 주소는 publish-log.md 에 적힌다.

SNS 계정을 아직 연결하지 않았다면 이 단계는 건너뛰어도 된다. 영상 파일은 이미 손에 있으니 직접 올려도 그만이다.

한 번에 끝내고 싶다면 — /social-flow:autoproduce money "7월 환율 변동" 한 줄이 2·3단계를 사람 확인 없이 관통한다. 승인 대신 기계 검사 아홉을 세워 두고 하나라도 걸리면 사람을 기다린다. 영상 한 편에 드는 비용은 대략 $0.05 수준이다.

SNS 에 올리려면

게시는 각 플랫폼의 API 토큰이 있어야 한다. 토큰 파일이 있는 플랫폼의 게시·인사이트 툴만 나타나므로 설치 직후에 안 보이는 건 정상이다.

직접 받는 대신 맡기는 방법

계정 개설부터 토큰 발급까지 브라우저를 대신 몰아 주는 스킬이 플랫폼마다 있다. 로그인·인증번호 입력처럼 사람 손이 꼭 필요한 지점만 넘겨받는다.

/social-flow:setup-threads money
/social-flow:setup-instagram money
/social-flow:setup-youtube money

토큰을 두는 자리

채널마다 폴더 하나를 쓴다. 여러 브랜드를 굴려도 계정이 섞이지 않는다.

~/.config/social-flow/<채널slug>/
├── threads_token
├── instagram_token
├── facebook_page_token
└── youtube-oauth-client.json

파일 권한은 chmod 600 으로 잠근다. 발급 절차는 skills/publish/references/token-setup.md 에 플랫폼별로 적혀 있다.

게시 도구는 부르는 순간 공개된다. 검토 단계나 임시 저장이 없다. 그래서 publish 스킬의 승인 화면과, 호출할 때마다 뜨는 Claude Code 권한 창이 이중으로 막아 준다. 권한 창을 "항상 허용"으로 올리지 않기를 권한다.

더 할 수 있는 것

채널 로고 만들기

후보 넷을 만들어 고르게 하고 고른 안을 검토 에이전트가 95점까지 다듬는다.

/social-flow:branding money

채널 인트로 영상

캐릭터가 연기하는 4초 인트로. 본편 앞이 아니라 뒤에 붙인다 — 앞 3초를 브랜드가 먹으면 넘겨진다.

/social-flow:intro money

화면 녹화로 만들기

웹 조사 대신 내 화면과 목소리를 소재로 쓴다. 받아쓰기해서 타임라인으로 바꿔 준다.

/social-flow:ingest money record

대본 보며 촬영하기

시연·튜토리얼용. 대본을 먼저 쓰고 그걸 보며 녹화한 뒤 편집한다.

/social-flow:storyboard money <주제> 촬영 대본으로

공공데이터 찾기

data.go.kr 에서 근거가 될 통계를 찾아 소재로 쟁여 둔다.

/social-flow:datago 전세 사기 통계

계정 스스로 키우기

승인해 둔 성장 계획 범위 안에서 댓글 응대·지표 관찰·게시를 자율로 돈다.

/social-flow:grow-threads money init

성장 루프는 한 번 계획을 승인하고 나면 /loop 30m /social-flow:grow-threads money 처럼 주기를 걸어 돌린다. 나가는 모든 문장은 검토 에이전트의 95점 기준을 넘어야 게시된다. 플랫폼별 자세한 전략은 스레드 · 유튜브 쇼츠 · 인스타그램 가이드에 정리돼 있다.

막혔을 때

/mcp 에 social-flow 가 안 보인다

대개 npm install 을 안 한 경우다. 저장소에는 빌드 결과만 있고 라이브러리는 들어 있지 않다. 직접 실행해 보면 원인이 바로 나온다.

cd ~/social-flow && node server/dist/index.js

social-flow MCP server started 가 찍히면 서버는 멀쩡하니 플러그인 등록 쪽을 다시 본다.

게시 도구가 목록에 없다

정상이다. 자격증명 파일이 있는 플랫폼의 도구만 나타난다. 토큰을 새로 넣었다면 Claude Code 를 다시 띄우지 않아도 목록을 다시 볼 때 반영된다.

data 폴더가 엉뚱한 곳에 생겼다

data/ 는 Claude Code 를 띄운 위치에 만들어진다. 작업 폴더를 하나 정해 늘 그 안에서 claude 를 실행하면 흩어지지 않는다.

영상 만드는 중에 멈춘다

ffmpeg -version 부터 확인한다. 화면 캡처 단계에서 멈춘다면 Chrome 이 깔려 있는지도 본다.

목소리가 이상하게 끊긴다
