GETTING STARTED

설치부터 첫 영상까지

social-flow 는 주제 하나를 받아 쇼트폼 영상과 SNS 글을 만들고, 사람이 승인하면 계정에 올려 주는 Claude Code 플러그인이다. 설치는 5분, 첫 영상은 명령 네 줄이면 나온다.

무엇을 하는 도구인가

영상 한 편을 올리려면 보통 이런 일을 한다. 자료를 찾고, 대본을 쓰고, 그림을 구하고, 목소리를 입히고, 자막을 달고, 플랫폼마다 다른 글을 따로 쓴다. social-flow 는 이 과정을 네 단계 명령으로 묶어 놓은 도구다.

STEP 1 채널 누구에게 어떤 말투로 말할지 한 번 정한다
STEP 2 스토리보드 자료를 찾아 대본과 씬 그림을 만든다
STEP 3 제작 영상 한 벌 + 플랫폼별 글을 뽑는다
STEP 4 게시 사람이 확인하고 승인하면 올린다

앞 단계가 끝나야 다음 단계가 돈다. 순서를 건너뛰면 그 자리에서 멈추고 무엇이 빠졌는지 알려 준다.

알아 두면 좋은 세 가지

  • 영상 포맷은 두 가지다. 기본은 9:16 세로(1080×1920 · 30fps) 한 벌이고 릴스·쇼츠·스레드로 각각 내보낸다. 유튜브 롱폼은 16:9 가로(1920×1080)다. 어느 쪽인지는 스토리보드를 쓸 때 고르고, scenes.js 의 window.FORMAT 한 줄이 캔버스·길이·자막 같은 뒤 단계 값을 한꺼번에 정한다.
  • 같은 글을 여러 곳에 복붙하지 않는다. 사실은 하나를 쓰되 문장은 플랫폼마다 다시 쓴다. 스레드는 반말 구어체, 유튜브는 검색되는 제목·설명처럼 성격이 다르기 때문이다.
  • 기본 흐름에는 사람 승인이 두 번 있다. 스토리보드를 확정할 때와 실제로 올리기 직전이다. 예외는 성장 루프 하나다 — 계정을 스스로 키우는 grow-* 스킬은 처음 한 번 승인받은 성장 계획이 게시별 승인을 대신한다. 그 범위 안에서는 묻지 않고 올리므로 계획을 승인할 때 범위를 좁게 잡는 편이 좋다.

준비물

맥이나 리눅스 터미널, 그리고 Claude Code 가 이미 깔려 있다고 보고 시작한다.

ffmpeg 필수brew install ffmpeg영상·소리를 자르고 붙인다. 없으면 3단계에서 멈춘다

설치

1

마켓플레이스에서 설치한다

Claude Code 안에서 두 줄이면 끝난다. 서버가 의존성까지 품은 단일 번들이라 내려받아 빌드할 것이 없다.

/plugin marketplace add ttalkkaklab/social-flow
/plugin install social-flow@social-flow

터미널이 편하면 claude plugin marketplace add ttalkkaklab/social-flow 뒤에 claude plugin install social-flow@social-flow — 같은 일을 한다.

공개 저장소다. 인증 없이 받아지고 라이선스는 Apache 2.0 이다.
2

작업할 폴더를 정하고 그 안에서 Claude Code 를 띄운다

만들어진 영상·대본은 data/ 폴더에 쌓이는데 이 폴더는 Claude Code 를 띄운 위치에 생긴다. 플러그인을 내려받은 곳이 아니다. 그래서 작업 폴더를 하나 정해 두고 늘 거기서 시작하는 편이 낫다.

# 예: 홈 아래에 작업 폴더 하나
mkdir -p ~/social-work && cd ~/social-work
claude
3

(선택) 코드를 고치며 쓰려면 클론으로 붙인다

스킬이나 서버를 직접 손볼 사람만 해당한다. 클론을 가리켜 띄우면 그 세션은 클론의 코드를 쓴다.

git clone https://github.com/ttalkkaklab/social-flow.git ~/social-flow
claude --plugin-dir ~/social-flow

실행은 이대로 되고, server/src 를 고쳤을 때만 cd ~/social-flow/server && npm install && npm run check 로 빌드와 자체 점검 테스트를 돌린다. 외부 API 를 부르지 않아 키가 없어도 통과한다.

Claude Code 밖에서도 붙는다. Grok CLI 는 grok plugin install https://github.com/ttalkkaklab/social-flow.git --trust 한 줄로 스킬·MCP 툴까지 전부 연결되고(grok 1.0.5 실측), Codex CLI 는 codex plugin marketplace add ttalkkaklab/social-flow 뒤 codex plugin add social-flow@social-flow 로 스킬 18종이 뜬다 — MCP 툴은 codex 0.147.0 기준 아직 연결되지 않는다. 키는 Claude 와 같은 셸 환경변수 경로다.
4

제대로 붙었는지 본다

/mcp 를 치면 연결된 서버 목록이 나온다. social-flow 가 있고 도구 목록이 보이면 끝났다.

도구가 52개만 보여도 정상이다. 전체 61종 가운데 게시·인사이트 툴 9종은 그 계정의 자격증명 파일이 있는 플랫폼만 나타난다. 아직 계정을 연결하지 않았다면 안 보이는 게 맞다.

API 키 넣기

키는 두 묶음이고 서로 상관이 없다. 어느 쪽에서 멈춰도 도구는 쓸 만하다.

  • 제작 키 — 영상을 만드는 쪽이다. OPENAI_API_KEY 와 GEMINI_API_KEY 둘이면 첫 영상이 나온다.
  • 플랫폼 자격증명(스레드·인스타그램·유튜브·페이스북) — 선택이다. 넣으면 올리는 일과 계정 운영까지 도구가 맡고, 안 넣으면 완성된 영상 파일과 플랫폼별 글이 output/ 에 놓이고 올리는 것만 손으로 한다.

키를 어디에 적나

키는 설정 파일이 아니라 셸 환경변수로 넣는다. ~/.zshrc(또는 ~/.bashrc)에 적고 터미널을 새로 열면 된다.

export OPENAI_API_KEY="sk-..."     # 커버·글자 들어간 화면
export GEMINI_API_KEY="..."        # 생성 영상·연기 목소리·배경음악

# 아래는 전부 선택
export NAVER_CLIENT_ID="..."       # 한국어 자료 조사
export NAVER_CLIENT_SECRET="..."
export SERPAPI_API_KEY="..."       # 정밀·해외 검색
export ARK_API_KEY="..."           # 두 번째 영상 엔진(Seedance)
export SUNO_API_KEY="..."          # 보컬 풀송·Suno 루프 BGM (sunoapi.org, Gemini 아님)
export ELEVENLABS_API_KEY="..."    # 세 번째 음성 레인 — 연기 컷·3인 이상 대화·타임스탬프
export DATA_GO_KR_API_KEY="..."    # 공공데이터 API 호출
키 값을 저장소 안에 적지 않는다. .mcp.json 은 셸 환경변수를 서버로 넘겨줄 뿐이라 커밋되는 파일 어디에도 키가 들어가지 않는다. 값이 없으면 그 키를 쓰는 도구만 부르는 순간 "키가 없다"고 분명히 알려 주고 나머지는 그대로 돈다. 세션은 띄울 때의 환경변수를 그대로 들고 간다 — 여기 적는 API 키를 새로 넣었으면 claude 를 다시 띄워야 반영된다. 파일로 두는 플랫폼 토큰은 이야기가 다르다(아래 참조).

키가 아예 없어도 되는 엔진 둘

애플 실리콘 맥이라면 씬 배경과 내레이션은 키도 네트워크도 과금도 없이 기기 안에서 만든다. 대신 처음 한 번 설치한다.

  • image_local_generate (Z-Image Turbo) — uv tool install --python 3.12 mflux. 첫 호출 때 가중치 31GB 를 내려받는다. 그림 안에 글자를 넣지 못한다.
  • tts_local_generate (Supertonic 3) — pip install supertonic. 첫 호출 때 가중치 385MB 를 ~/.cache/supertonic3 로 내려받는다(20여 초). 가상환경에 깔았으면 SUPERTONIC_PYTHON 에 그 파이썬 경로를 적는다. 연기·감정 지시가 없어서 인트로 대사나 캐릭터 대사는 tts_generate(Gemini) 쪽으로 보낸다.

플랫폼 자격증명은 선택이다

스레드·인스타그램·유튜브·페이스북 토큰은 플랫폼별로 따로 넣는다. 유튜브만 연결해 두면 유튜브만 올라가고 스레드·인스타는 손으로 올리는 식이라, 전부 아니면 전무가 아니다.

  • 넣으면 — publish 가 계정에 직접 올리고, grow-* 스킬이 /loop 로 댓글 응대·지표 관찰·키워드 대화·대기열 보충·게시까지 스스로 돈다. 범위는 init 때 한 번 승인한 성장 계획이 정한다.
  • 안 넣으면 — 조사·스토리보드·이미지·목소리·빌드까지 그대로 돌아간다. produce 가 완성 영상과 플랫폼별 글을 data/<채널>/episodes/<주제>/output/ 에 써 주고, 그 파일을 직접 올리면 된다. 게시·인사이트 툴 9종이 목록에 안 나오고 성장 루프가 돌 거리가 없을 뿐이다.

토큰은 환경변수가 아니라 파일이라, 나중에 넣어도 서버를 다시 띄울 필요가 없다. 도구 목록을 다시 볼 때 그 플랫폼 도구가 붙어 52종이 61종 쪽으로 늘어난다. 계정 개설과 토큰 발급 절차는 아래 6장에 있다.

키가 살아 있는지 보기

영상을 한 편 태워 보기 전에 두 줄로 확인한다. 둘 다 목록 조회라 과금이 붙지 않는다.

curl -s https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | head -c 200

curl -s "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY" | head -c 200

모델 목록이 JSON 으로 돌아오면 된 것이다. 401·403 이면 키 값이 틀렸거나 결제 수단이 안 걸려 있다. 플랫폼 토큰은 sns_account_check 도구가 한 번에 확인해 준다 — 토큰 값은 찍지 않고 어느 계정으로 붙었는지만 보여 준다.

첫 영상 만들어 보기

재테크 채널로 환율 영상 한 편을 만든다고 하자. Claude Code 안에서 명령을 차례로 친다.

1

채널을 만든다 — 채널당 한 번

/social-flow:channel add 재테크

맨 먼저 채널명을 영문 slug 로 바꿔 제안한다 — "재테크"라면 money 같은 것이다. 폴더 이름과 게시 계정 키로 쓰이는 값이라 한글을 쓰지 않는다. 이 다음부터 명령에 넣는 채널은 원래 이름이 아니라 이 slug 다.

이어서 누가 보는지, 어떤 말투로 말할지, 어디에 올릴지를 몇 가지 물어본 뒤 data/money/profile.md 에 적어 둔다. 이후 모든 작업이 이 파일을 먼저 읽어 톤과 목소리를 이어받는다.

내레이션 목소리도 여기서 하나 정해 고정한다. 회차마다 목소리가 바뀌면 같은 채널로 안 들리기 때문이다.

2

스토리보드를 만든다 — 가장 오래 걸리는 단계

/social-flow:storyboard money "7월 환율 변동"

맨 먼저 포맷을 묻는다 — 9:16 쇼트폼이 기본이고, 챕터가 있는 유튜브 롱폼이면 16:9 다. 그다음 자료를 찾고, 시나리오 후보 세 개를 호기심·공포·궁금증·코믹으로 95점까지 돌린 뒤 고르게 하고, 고른 쪽으로 더 조사한 다음, 씬을 나누고, 대사를 쓰고, 씬마다 그림을 만든다. 결과는 브라우저로 열어 볼 수 있는 storyboard.html 로 나온다.

사람에게 보여 주기 전에 검토용 에이전트가 여섯 번, 한 번씩 읽는다 — 문장이 AI 가 쓴 티가 나는지, 씬 하나하나가 제 역할을 하는지, 낱말이 사람이 쓰는 말인지, 카메라를 어떻게 움직이고 어디서 멈출지 정해 뒀는지, 소리가 어떻게 날지, 그림이 그 씬 내용과 맞는지. 지적을 한 번 반영하고 넘어가며, 못 고친 지적은 승인 화면에 그대로 올라온다. 여기서 시간이 걸리는 건 정상이다. 마지막에 확인 요청이 오면 승인한다.

3

영상과 글을 뽑는다

/social-flow:produce money 20260729-fx

주제 이름은 2단계가 만든 폴더 이름을 그대로 쓴다. 화면을 그려 캡처하고, 목소리를 입히고, 배경음악을 깔고, 자막을 붙여 영상을 만든다. 여기에 스레드·인스타·페이스북·유튜브용 글이 각각 따로 나온다.

결과물은 data/money/episodes/20260729-fx/output/ 에 있다. 자막을 화면에 태운 영상과 태우지 않은 영상이 따로 나오는데 인스타는 자막 파일을 못 받아 태운 쪽을 쓰고 유튜브·페이스북은 자막을 따로 올린다.

4

올린다

/social-flow:publish money 20260729-fx

플랫폼별 최종 문안과 올라갈 계정을 전부 보여 주고 승인을 받는다. 승인해야 실제 호출이 나가고 올라간 주소는 publish-log.md 에 적힌다.

SNS 계정을 아직 연결하지 않았다면 이 단계는 건너뛰어도 된다. 영상 파일은 이미 손에 있으니 직접 올려도 그만이다.

한 번에 끝내고 싶다면 — /social-flow:autoproduce money "7월 환율 변동" 한 줄이 2·3단계를 사람 확인 없이 관통한다. 시나리오 후보 세 개는 호기심·공포·궁금증·코믹으로 95점까지 돌리고 최고점을 고른 뒤 그쪽으로 더 조사한 다음 쓴다. 승인 대신 기계 검사를 세워 두고 하나라도 걸리면 사람을 기다린다. 기본값인 경제 티어는 생성 영상을 한 컷도 부르지 않아서 영상 한 편에 대략 $0.26~0.29 가 든다(상한 $0.30).

SNS 에 올리려면

게시는 각 플랫폼의 API 토큰이 있어야 한다. 토큰 파일이 있는 플랫폼의 게시·인사이트 툴만 나타나므로 설치 직후에 안 보이는 건 정상이다.

이 장은 통째로 건너뛰어도 된다. 토큰이 하나도 없어도 3단계까지는 그대로 돌아가고, output/ 에 놓인 영상과 플랫폼별 글을 직접 올리면 된다. 토큰은 플랫폼별로 따로라 유튜브만 먼저 연결해 두는 것도 된다 — 그러면 유튜브는 도구가 올리고 나머지는 손으로 올리는 상태가 된다. 토큰을 넣는 순간 게시뿐 아니라 성장 루프와 지표 조회도 함께 열린다.

직접 받는 대신 맡기는 방법

계정 개설부터 토큰 발급까지 브라우저를 대신 몰아 주는 스킬이 플랫폼마다 있다. 로그인·인증번호 입력처럼 사람 손이 꼭 필요한 지점만 넘겨받는다.

/social-flow:setup-threads money
/social-flow:setup-instagram money
/social-flow:setup-youtube money

토큰을 두는 자리

채널마다 폴더 하나를 쓴다. 여러 브랜드를 굴려도 계정이 섞이지 않는다.

~/.config/social-flow/<채널slug>/
├── threads_token
├── instagram_token
├── facebook_page_token
└── youtube-oauth-client.json

파일 권한은 chmod 600 으로 잠근다. 발급 절차는 skills/publish/references/token-setup.md 에 플랫폼별로 적혀 있다.

게시 도구는 부르는 순간 공개된다. 검토 단계나 임시 저장이 없다. 그래서 publish 스킬의 승인 화면과, 호출할 때마다 뜨는 Claude Code 권한 창이 이중으로 막아 준다. 권한 창을 "항상 허용"으로 올리지 않기를 권한다.

더 할 수 있는 것

채널 로고 만들기

후보 넷을 만들어 고르게 하고 고른 안을 검토 에이전트가 95점까지 다듬는다.

/social-flow:branding money

채널 인트로 영상

캐릭터가 연기하는 4초 인트로. 본편 앞이 아니라 뒤에 붙인다 — 앞 3초를 브랜드가 먹으면 넘겨진다.

/social-flow:intro money

화면 녹화로 만들기

웹 조사 대신 내 화면과 목소리를 소재로 쓴다. 받아쓰기해서 타임라인으로 바꿔 준다.

/social-flow:ingest money record

대본 보며 촬영하기

시연·튜토리얼용. 대본을 먼저 쓰고 그걸 보며 녹화한 뒤 편집한다.

/social-flow:storyboard money <주제> 촬영 대본으로

공공데이터 찾기

data.go.kr 에서 근거가 될 통계를 찾아 소재로 쟁여 둔다.

/social-flow:datago 전세 사기 통계

계정 스스로 키우기

승인해 둔 성장 계획 범위 안에서 댓글 응대·지표 관찰·게시를 자율로 돈다.

/social-flow:grow-threads money init

성장 루프는 한 번 계획을 승인하고 나면 /loop 30m /social-flow:grow-threads money 처럼 주기를 걸어 돌린다. 나가는 모든 문장은 검토 에이전트의 95점 기준을 넘어야 게시된다. 플랫폼별 자세한 전략은 스레드 · 유튜브 쇼츠 · 인스타그램 가이드에 정리돼 있다.

막혔을 때

/mcp 에 social-flow 가 안 보인다

서버부터 직접 띄워 본다 — 원인이 바로 나온다. 마켓플레이스로 깔았으면 설치 캐시에서, 클론이면 클론 폴더에서.

node ~/.claude/plugins/cache/social-flow/social-flow/*/server/dist/bundle.js
# 클론이면: cd ~/social-flow && node server/dist/bundle.js

social-flow MCP server started 가 찍히면 서버는 멀쩡하니 플러그인 등록 쪽을 다시 본다. 구버전 Claude Code 에서 claude plugin update social-flow 가 not found 를 내면 uninstall 뒤 install 로 다시 깐다.

게시 도구가 목록에 없다

정상이다. 자격증명 파일이 있는 플랫폼의 도구만 나타난다. 토큰을 새로 넣었다면 Claude Code 를 다시 띄우지 않아도 목록을 다시 볼 때 반영된다.

data 폴더가 엉뚱한 곳에 생겼다

data/ 는 Claude Code 를 띄운 위치에 만들어진다. 작업 폴더를 하나 정해 늘 그 안에서 claude 를 실행하면 흩어지지 않는다.

영상 만드는 중에 멈춘다

ffmpeg -version 부터 확인한다. 화면 캡처 단계에서 멈춘다면 Chrome 이 깔려 있는지도 본다.

목소리가 이상하게 끊긴다

긴 문장 하나를 통째로 읽히면 뒤쪽이 흐트러질 때가 있다. 대사를 짧게 끊어 다시 만들면 대개 해결된다.

스토리보드에서 오래 걸린다

검토 에이전트가 여섯 번 읽고 그림을 만드는 중이다. 같은 곳을 두 번 읽지는 않는다 — 여섯 번이 끝나면 못 고친 지적을 함께 보여 주고 사람 판단을 기다린다.
