01결론 요약

VERDICT
대량 나레이션용은 아니다 — Gemini의 1.3~2.6배 값이다. 대신 우리 파이프라인의 우회 코드 두 곳을 정면으로 없앤다: 다화자 씬(요청 하나에 보이스 10종)과 자막 동기(글자 단위 타임스탬프 native 반환).

감정 연기 컷은 v3 오디오 태그([laughs]·[whispers]·[sarcastic])가 Gemini 연기 지시문과 경쟁한다. 상업 게시는 Starter($6)부터, 한국어 커뮤니티 보이스·전문 복제(PVC)는 Creator($22)부터다. 한국어 실제 음질은 샘플을 들어 봐야 판정할 수 있다 — 49종 청취 문서 방식의 후속 작업이 필요하다.

03API 구조와 파라미터

인증은 xi-api-key 헤더 하나다. 엔드포인트는 용도별로 넷.

엔드포인트반환용도
POST /v1/text-to-speech/{voice_id} 오디오 바이너리 기본 합성
…/{voice_id}/stream 오디오 스트림 HTTP 스트리밍 재생
…/{voice_id}/with-timestamps audio_base64 + alignment 글자별 시작·끝 초 — 자막 동기용. 정규화 전·후 정렬(normalized_alignment) 둘 다 온다. 모델별 지원 여부는 문서에 명시가 없다 — 실측 항목(v3는 출시 초기에 미지원이었다)
POST /v1/text-to-dialogue 오디오 바이너리 다화자 대화. inputs: [{text, voice_id}…] 배열, 기본 모델 eleven_v3, 보이스 최대 10종, 요청당 총 2,000자 권장

본문 파라미터

  • model_id — 기본 eleven_multilingual_v2
  • language_code — ISO 639-1 강제 지정. multilingual_v2는 이 파라미터를 지원하지 않고, 2026-07부터 미지원 코드는 거부 대신 무시된다 2차
  • output_format — 기본 mp3_44100_128. mp3 22.05~44.1kHz·32~192kbps / PCM 8~48kHz / μ-law·A-law 8kHz / Opus 48kHz. 고품질 포맷은 유료 플랜용
  • seed — 0~4294967295. 같은 요청의 결정적 재현
  • previous_text / next_text — 문장을 나눠 합성할 때 앞뒤 문맥을 넘겨 이음새 톤을 맞춘다
  • pronunciation_dictionary_locators — 발음 사전 최대 3개. 고유명사 발음 교정 창구
  • apply_text_normalization — auto/on/off. 숫자·날짜 읽기 변환

voice_settings

  • stability 0~1 (기본 0.5) — 높을수록 일정하고 단조로움
  • similarity_boost (기본 0.75) — 원화자 유사도
  • style (기본 0) — 과장 강도. 올리면 지연도 는다
  • use_speaker_boost (기본 true), speed (기본 1.0)
파이프라인 관점 메모

seed + previous_text/next_text 조합은 우리처럼 문장 단위로 끊어 합성·검수·재합성하는 흐름과 잘 맞는다. 특정 문장만 다시 만들 때 앞뒤 문맥을 주면 이어붙인 티가 덜 난다. 발음 교정도 지금처럼 표기를 바꿔치기(「에이트」류)하는 대신 발음 사전으로 정식 처리할 수 있다.

04v3 오디오 태그 — 감정 연출

본문에 대괄호 태그를 심으면 그 자리에서 연기가 바뀐다. Gemini TTS의 프롬프트 지시문("차분하게 읽어줘")보다 위치 제어가 정밀하다.

  • 감정·전달 — [laughs] [laughs harder] [whispers] [sighs] [sarcastic] [curious] [excited] [crying] [mischievously]
  • 효과음 — [applause] [clapping] [explosion] [gulps] 등
  • 실험적 — [sings] [strong X accent] 등. 일관성이 떨어져 주의 표기가 붙어 있다

태그 효과는 보이스의 학습 샘플 성격을 탄다 — 속삭이는 보이스에 [shout]를 붙여도 설득력 있게 소리치지 못한다. v3의 stability는 슬라이더가 아니라 3모드다: Creative(표현 최대·환각 위험)·Natural(균형)·Robust(안정적이나 태그 반응 둔함). 태그를 쓰려면 Creative나 Natural을 고른다.

한국어 문안에서 태그가 얼마나 먹히는지는 문서에 없다. 실청취 검증 항목이다.

05목소리 — 라이브러리·복제

  • 기본 보이스는 2026-12-31에 만료되고 새 보이스 세트로 교체된다. 지금 기본 보이스에 파이프라인을 묶으면 연말에 갈아타야 한다.
  • Voice Library — 커뮤니티 공유 보이스 1만 종 이상. 제작자가 조건을 정하고 수익을 나눈다. 무료 티어 API에서는 못 쓴다.
  • IVC(즉석 복제) — 2분 미만 샘플로 복제. 대부분의 유료 플랜에서 가능
  • PVC(전문 복제) — 장시간 학습 오디오 + 본인 확인(voice captcha) 필수. Creator 플랜 이상. 품질은 IVC보다 위
  • Voice Design — 텍스트 설명(20~1,000자)으로 새 보이스 생성, 시안 3개 반환. v3 기반은 오디오 태그 대응 보이스를 만든다

06한국어 품질

문서상 지원과 실제 음질은 별개다. 커뮤니티 실사용 평의 공통 결론은 "영어 기본 보이스로 한국어를 돌리면 외국인 억양이 난다 — 한국어 화자가 만든 PVC 보이스를 Voice Library에서 골라야 자연스럽다"이다 2차.

  • 2024년 무렵의 평가는 기계적 억양·어색한 호흡으로 박했고, v3에서 한국어 발음이 크게 나아졌다는 게 2026년 국내 블로그들의 일치된 평이다 2차
  • 결국 모델 선택보다 보이스 선택이 한국어 품질을 가른다는 얘기다 — 한국어 보이스 실청취 없이 도입 판단을 내릴 수 없다
미검증

한국어 보이스별 음질, v3 태그의 한국어 반응, 그리고 우리가 Gemini에서 겪은 길이 퇴화·받침 탈락류 함정의 재현 여부 — 셋 다 들어 보기 전엔 모른다. 2026-08-11 조사의 49종 청취 문서와 같은 방식의 샘플 페이지가 후속 작업이다.

08social-flow 파이프라인 대응

지금 우리가 하는 일ElevenLabs로 하면
3화자 씬 — Gemini tts_multi_speaker가 2화자 상한이라 화자별 콜 + 쉼 0.75초 이어붙임 text-to-dialogue 한 요청에 보이스 10종. 우회 코드가 통째로 빠진다. 요청당 2,000자 상한이라 씬 단위 분할은 유지
자막 동기 — TTS 출력물을 ASR로 되읽어 단어 타임스탬프 추출·검증 with-timestamps가 글자 단위 정렬을 합성과 같이 반환. 재STT 단계가 사라진다
감정 연기 컷 — Gemini TTS 프롬프트 지시문 v3 오디오 태그가 문장 안 정확한 위치에 연기를 건다. 5,000자 상한·실시간 불가는 사전 렌더 파이프라인엔 무관
발음 교정 — 표기 바꿔치기(「에이트」류) 발음 사전(pronunciation dictionary) 최대 3개로 정식 관리
대량 나레이션 — Supertonic 로컬(0원) / Gemini($38/100만 자) 여기는 안 바꾼다. Flash $50·표준 $100은 대량용으로 비싸다

도입한다면 자리는 셋 — 다화자 씬, 감정 연기 컷, 그리고 자막 타임스탬프. 최소 플랜은 상업 게시 조건 때문에 Starter($6)가 바닥이고, 한국어 커뮤니티 보이스와 PVC까지 쓰려면 Creator($22)다. 딸깍랩 4배역(Charon·Kore·Leda·Zubenelgenubi)을 옮기려면 비슷한 색의 한국어 보이스를 Voice Library에서 찾아 실청취로 고르는 작업이 선행돼야 한다.

다음 단계 (도입을 결정할 경우)

① 무료 티어로 한국어 기본 보이스 실청취(단 Voice Library는 유료 전환 후) → ② 49종 문서 형식의 한국어 샘플 페이지 → ③ 3화자 씬 하나를 text-to-dialogue로 재현해 Gemini 이어붙임본과 A/B → ④ with-timestamps 정렬을 build 스크립트 자막 입력과 맞대 보기.
