# 대화극의 재미와 맥락을 함께 쓰기

조사일: 2026-10-18. 범위: 기존 프로젝트 문서와 작가의 1차 자료. 아래 작성 방법은
실무 조언을 이 프로젝트에 적용한 판단이다. 시청 유지율이나 웃음의 효과를 실험으로
입증한 규칙이 아니며 영상·음성 품질 평가와 구별한다.

## 프로젝트 문서에서 확인한 것

- [기존 시나리오 조사](../2026-08-25-scenario-craft/index.html)의 코미디 절은 패턴과
  펀치라인 중심이다. 서브텍스트는 대사 분량이 커지면 재검토한다고 적었다. 지금의
  대화극에는 상대에게 무엇을 얻으려는 말인지, 알고도 숨기는 것은 무엇인지가 필요하다.
- [이야기 우선 개정 기록](../../loops/005-story-first/release-notes.md)은 고립된 대사와
  설명에만 있는 인과를 이미 문제로 다뤘다. 네 평가작의 높은 점수가 다른 기존 보드의
  후속 장면까지 검토했다는 증거는 아니다.
- [현재 작성 지침](../../../skills/storyboard/references/character-scenarios.md)은
  지식 전달, 완결된 장면, 블라인드 독해를 요구한다. 이번 사례는 규칙 부재만으로
  설명되지 않는다. 기존 장면을 유지할 때도 그 장면까지 읽는 절차가 필요하다.
- [음성 자연스러움 기록](../2026-09-12-narration-naturalness/README.md)은 발음·음색·합성
  검증이다. 대사가 자연스럽게 들리는 이유와 사건이 자연스럽게 이어지는 이유는 다르다.
  과거 음성 승인 기준은 현재 CLAUDE.md 지시로 대체됐으므로 복원하지 않는다.

## 개선 범위

1. 결정적인 대사 직전에 발화 계기, 상대, 말로 하려는 일, 판단 근거를 사건에서 찾는다.
   이름을 아는 것과 신분·비밀을 아는 것을 구별한다. 장면마다 표를 채우는 의무는 없다.
2. 코미디는 인물마다 다른 대응 방식에서 만든다. 장난스러운 문장을 이어 붙이지 않는다.
   웃음에 필요한 기대를 먼저 전달하고 행동이나 반응으로 어긋나게 한다. 설명으로 웃음을
   해설하지 않는다. 위험의 피해자 대신 허세·은폐의 수고·상반된 이해관계가 웃음의 대상이다.
3. 재작성은 전체 기존 장면을 대상으로 한다. 유지한 부분도 새 앞뒤 장면과 맞는지 읽는다.
   이전 컷 번호, 대사 수신자, 엔딩 참조, 이전 리뷰를 그대로 승계하지 않는다.
4. 블라인드 독해에서는 이해한 사건뿐 아니라 웃음의 기대와 어긋남, 예상되는 다음 행동도
   묻는다. 재미를 평범한 설명으로 바꿔 점수를 올리지 않는다.
5. 점수가 모자라면 일반화할 수 있는 원인을 플러그인에 반영한다. 설치 후 작성자가 새
   지침을 읽고 다음 개정본을 쓴다. 평가자는 대본을 고치지 않으며 목표 점수를 보지 않는다.

## 이번 내용 평가 기준

총 100점: 인과·이해 25 / 인물의 지식·동기 20 / 상황의 재미 20 / 설정·회수 20 /
대사·호흡 15. 이미지, 렌더링, 음성, 실제 연기와 시청 지표는 평가하지 않는다.
통과는 사용자가 요청한 **95점 초과**, 핵심 사건을 무너뜨리는 결함(P0) 0건이다.
95점은 통과가 아니다. 이 기준은 이번 반복 작업의 기준이며 일반 제작의 실행 조건이 아니다.
리뷰마다 다섯 축과 감점 근거를 보존하고 목표에 맞춰 점수를 조정하지 않는다.
