# 한국 드라마 클리셰 조사

확인일: 2026-11-18. 한국 드라마에 되풀이되는 장치·장면·인물·대사·연출을 기사, 나무위키, 영어권 팬 목록에서 모아 겹치는 항목을 합치고 번호를 매겼다. 이 조사는 storyboard 스킬의 클리셰 선택 단계(`skills/storyboard/references/cliche-use.md`)가 쓰는 목록의 근거다.

## 이 폴더에 있는 것

- `index.html` — 시각 요약. 묶음별 개수, 근거 수준, 해외 목록 빈도, 시대별 변천, 반복되는 이유, 비판 사례, 전체 목록 검색.
- `reports/한국 드라마 클리셰 총정리.md` — 번호 1~371의 목록(한 줄 설명, 대표 작품, 근거 수준, 출처 링크)과 분석 다섯 절, 출처를 찾지 못한 항목 표.
- `research_notes/한국 드라마 클리셰 총정리/` — 조사 노트 아홉 편. 로맨스, 가족극·막장, 장르물, 연출·형식, 인물·대사, 해외 시청자, 변천사, 그리고 보강 두 편이다.

## 확인 범위

- 조사는 일곱 갈래로 나눠 웹 검색과 원문 열람으로 했고, 비어 있던 두 곳(나무위키 장르 문서, 출처가 없던 장면)을 한 번 더 보강했다.
- 근거 수준은 넷이다. 본문은 페이지를 열어 확인한 기사·매체 글, 나무는 나무위키 문서, 커뮤는 팬 게시판과 회원 공동 목록, 요약은 검색 결과 요약만 본 것이다.
- 371개 가운데 본문 근거가 있는 항목은 148개다. 나머지 223개는 나무위키, 팬 목록, 검색 요약에 기댄다.
- 학술 논문 본문은 거의 열지 못했다. TV Tropes, 레딧, MyDramaList는 접속이 막혀 검색 요약만 썼다.

## 읽을 때 주의할 점

- 371은 기록된 관찰의 개수다. 어떤 클리셰가 얼마나 자주 쓰이는지를 뜻하지 않는다.
- 연도 뒤 † 는 출처가 방영 연도를 적지 않아 조사자가 보충한 값이다. 확인된 사실로 옮기지 않는다.
- 영어 제목만 확인한 2025~2026년 작품은 「한국어 제목 미확인」으로 적혀 있다.
- 노트끼리 연도나 제목이 다른 곳은 고치지 않고 그대로 두었다.
- "Truck-kun"은 일본 이세계물에서 나온 밈이다. K드라마 팬은 같은 장면을 "Truck of Doom"이라 부른다.

## 플러그인이 쓰는 방식

- `skills/storyboard/references/cliche-catalog.json`이 이 보고서에서 나왔다. 번호 1~371은 보고서의 번호와 같고, 그 뒤 97개는 널리 알려졌지만 출처를 찾지 못한 항목이다(`evidence: "unverified"`).
- 목록의 층, 필요, 장르, 주의 표시는 보고서에 있는 내용이 아니다. 플러그인이 항목 설명을 읽고 붙인 편집 판단이다. 기준은 `docs/loops/025-cliche-use/tagging-spec.md`에 있다.
- 주의 표시의 근거는 보고서의 비판 절이다. 강압적 스킨십은 경향신문 2016년 기사와 방송통신심의위원회의 2017년 지적, 폭력 수위는 2021년 법정제재 보도에 기댄다.
- 클리셰를 넣은 에피소드가 시청 지속에 도움이 되는지는 우리 채널에서 재지 않았다.
