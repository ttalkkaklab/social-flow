맥북에서 쓸 TTS — 로컬 오픈소스와 상용 API

social-flow 나레이션 파이프라인의 음성 합성 선택지를 정리한다. 로컬 모델 두 종은 이 맥에서 직접 실행해 속도와 발음 정확도를 측정했고, 상용 API 13종은 과금 단위가 제각각이라 한국어 100만 자 기준으로 환산해 비교했다.

작성일 2026-08-11 실측 환경 MacBook Pro M4 Max · 128GB 실측 모델 Supertonic 3 · Qwen3-TTS 1.7B 환산 대상 상용 API 13종
Supertonic 3 · F1 · 한국어 127자 · 실제 생성 산출물의 피크 파형 19.4s / 44.1kHz
결론
기본 나레이션은 로컬 Supertonic 3으로 돌리고, 목소리 복제가 필요한 컷만 Qwen3-TTS, 감정 연기가 들어가는 짧은 구간만 지금 쓰는 Gemini TTS를 유지한다.

이 맥은 통합 메모리 128GB라 모델 크기 제약이 사실상 없다. 그래서 선택 기준은 하드웨어가 아니라 한국어 발음 품질과 가중치 라이선스 둘이다. 이 기준으로 Supertonic 3은 385MB로 CPU만 써서 실시간의 6.3배를 냈고, 발음도 STT 왕복 검증을 통과했다. 상용 API는 한국어 100만 자당 $4~160으로 갈리는데, 현재 쓰는 Gemini 2.5 Flash TTS는 약 $38로 중간이다.

01 검증 환경

측정에 쓴 맥의 사양이다. GPU 40코어보다 통합 메모리 128GB가 결정적이다 — 별도 VRAM을 쓰는 PC와 달리 모델 크기 상한이 없어, 1.7B급 TTS를 여러 개 띄워놓고 비교해도 여유가 있다.

측정에 쓴 도구는 whisper-cli(whisper.cpp, large-v3-turbo), ffmpeg, uv로 만든 격리 파이썬 환경이다. 셋 다 이 맥에 이미 깔려 있다. 참고로 HuggingFace 캐시에는 Qwen3-TTS 1.7B(4.2GB)와 Chatterbox(3.0GB) 가중치가 이미 받아져 있었다.

발음 검증 방법

음성 품질은 사람 귀로 판단하면 기록에 남지 않는다. 그래서 생성한 음성을 다시 STT로 받아써서 원문과 대조하는 방식을 썼다. 숫자·영어 약어처럼 한국어 TTS가 흔히 틀리는 지점을 문장에 심어두면, 받아쓰기 결과가 원문과 어긋나는 자리가 곧 발음이 무너진 자리다.

02 Supertonic 3 실측

슈퍼톤(하이브 자회사)이 공개한 온디바이스 TTS다. ONNX 런타임으로 돌아 파이썬 말고도 Node·Swift·Rust·Flutter 등에서 같은 가중치를 그대로 쓴다. 31개 언어를 99M 파라미터로 처리한다. pip install supertonic 한 줄로 설치가 끝났고, 첫 음성까지 1분이 걸리지 않았다.

보이스는 모델에 딸려온 고정 10종(F1~F5 여성, M1~M5 남성)이고, 공개본에 음성 클로닝 파이프라인은 없다. 출력은 44.1kHz WAV다. 같은 문장을 F1·M1·F3으로 각각 뽑아 속도 편차를 봤는데 6.1~6.4배 사이로 일정했다.

한국어 문장은 그대로 복원됐고, 숫자와 영어 약어 다섯 개도 전부 살아남았다. 어긋난 자리는 띄어쓰기("읽어 볼게요")와 STT 쪽 표기 관습("35,000원", "11 Labs")뿐이라 발음 문제로 볼 수 없다.

기록 — 중간 관찰의 정정

첫 테스트에서 "API"가 "APA"로 받아써져 약어 처리가 약한 것으로 보고했으나, 약어를 다섯 개 몰아넣어 다시 시험하니 전부 정확했다. 재현되지 않으므로 약점으로 기록하지 않는다. 한 번의 관찰로 모델 특성을 단정하지 말 것.

라이선스 주의

코드는 MIT지만 가중치는 OpenRAIL-M이다. 상업 이용은 되되 용도 제한 조항이 붙으므로, 게시물 파이프라인에 넣기 전에 조항을 한 번 확인할 것.

03 Qwen3-TTS 실측

알리바바 Qwen 팀이 Apache-2.0으로 공개한 모델이다. 3초짜리 참조 음성으로 목소리를 복제하고, 말로 설명해 목소리를 만드는 보이스 디자인도 된다. 라인업은 0.6B와 1.7B이며, 이번엔 이미 캐시에 있던 Qwen3-TTS-12Hz-1.7B-CustomVoice를 MPS로 돌렸다.

한국어 sohee 포함

지원 언어는 chinese · english · french · german · italian · japanese · korean · portuguese · russian · spanish이고, 화자 프리셋에 한국어 이름 sohee가 있다. 발음은 Supertonic과 같은 방식으로 검증해 역시 전부 통과했다.

속도가 발목을 잡는다

같은 문장에 98.8초가 걸렸다. 실시간의 0.19배이고 Supertonic의 27분의 1이다. 화자를 sohee로 바꿔도 98.4초로 같았다. flash-attn이 애플 실리콘에서 동작하지 않아 수동 PyTorch 경로로 떨어지는 것이 큰 원인이다. 나레이션을 통째로 뽑는 용도로는 쓰기 어렵고, 목소리 복제가 꼭 필요한 짧은 컷에 한정하는 게 맞다.

Kokoro(82M)·Chatterbox·VibeVoice는 "2026 최고의 오픈소스 TTS" 류 글에서 상위권으로 꼽히지만 한국어를 지원하지 않는다. 특히 Kokoro는 한국어가 된다고 적은 요약 글이 많은데, kokoro/pipeline.py의 LANG_CODES에는 영어(미/영)·스페인어·프랑스어·힌디어· 이탈리아어·포르투갈어·일본어·중국어만 있고 한국어가 없다. 소스를 직접 확인한 사항이다. 요약 사이트 대신 모델 카드나 소스를 볼 것.

빗금은 환산값이다 — 오디오 길이·크레딧·원화로 과금하는 것들이라 발화 속도나 환율에 따라 달라진다. 원화 환산은 1달러 1,390원 기준.

읽는 법

무료 구간이 생각보다 크다. Google Cloud는 음성 등급별로 월 100만~400만 자가 무료고, AWS Polly는 Standard 500만 자를 기간 제한 없이 준다. Gemini 2.5 Flash TTS에도 무료 티어가 있다. 쇼트폼 나레이션 분량이면 상당 부분 무료 구간에서 끝난다.

Gemini는 문자가 아니라 시간으로 센다. 오디오 토큰은 초당 25개로 계산되므로, 같은 대본이라도 읽기 속도를 올리면 그만큼 싸진다. 문자 과금 서비스에는 없는 조절 여지다.

CLOVA는 구조가 다르다. Premium 기본료 9만 원에 100만 자가 포함되고 넘으면 1,000자당 100원이다(VAT 별도). ncloud 요금계산기로 100만 자 9만 원, 200만 자 19만 원, 300만 자 29만 원을 확인해 역산한 값이다. 글로벌 서비스보다 비싸지만 한국어 억양은 여전히 강점이다.

환산이 애매한 항목

OpenAI gpt-4o-mini-tts는 오디오 출력 토큰 100만 개당 $12인데 초당 토큰 수가 공개돼 있지 않아 문자 단가로 정확히 옮기기 어렵다. 문자로 과금하는 tts-1($15) 기준으로 잡는 편이 안전하다.
