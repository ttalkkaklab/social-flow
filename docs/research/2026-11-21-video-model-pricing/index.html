    전체 단가표

    모델판매처출력·오디오공개 단가USD/초근거·조건출처계산

    좁은 화면에서는 표를 좌우로 밀어 출처와 비교 버튼을 볼 수 있다. 환산 USD/초는 참고용이다. 길이, 참조 영상 포함 여부, 오디오, 업스케일 및 플랜 종류가 같을 때 비교한다. 시작가·견적 미공개·입력 길이 연동·원화만 확인된 항목은 USD 순위에서 제외했다.

    과금 기준과 확인 범위

    토큰·입력 영상·최소 길이

    BytePlus는 (입력 영상 초 + 출력 초) × 출력 너비 × 출력 높이 × fps ÷ 1,024로 토큰을 추정한다. 영상 참조가 있으면 요율을 낮추고 최소 청구 토큰을 적용한다. 720p 5초의 무참조 공식 예시는 $1.156, 2–30초 입력 범위는 $1.244–$4.838이다. 11월 19일 갱신한 ModelArk 표에는 Seedance 2.5 4K와 2.5 Flash가 들어 있다. 같은 720p 5초라도 Flash 공식 예시는 $0.76이다. ModelArk 11월 19일 가격표

    Kie의 720p 예시는 무참조 $0.315 × 출력 5초 = $1.575다. 영상 5초를 참조하면 $0.19 × (입력 5초 + 출력 5초) = $1.90이다. Veo 3.1 Gemini API는 1080p·4K에서 8초가 필요하다. LTX 2.5 일반 6초 시작과 A2V 입력 오디오 청구도 실제 단가에 영향을 준다. Replicate는 720p Seedance 2.5를 영상 참조 없이 출력할 때 $0.2312/초, 영상 입력이 있을 때 $0.9676/출력 초로 표기한다. Replicate 모델 가격표 Kie 모델 카드 · Veo 계약 · LTX 계약

    구독 크레딧과 월 지출

    크레딧 환산은 플랜 가격 ÷ 포함 크레딧 × 생성 차감량이다. 실제 월 지출에는 구독료 전액과 초과 충전 비용이 들어간다. 예산 계산기는 충전 단가가 확인되지 않은 경우 부족한 크레딧만 계산한다. Magnific의 연간 풀처럼 연중 사용할 수 있는 크레딧은 연간 총량으로, Higgsfield처럼 월 배정하는 연간 상품은 월 배정량으로 계산한다. Magnific 플랜 · Higgsfield 플랜

    Relax·무제한은 적용 모델, 해상도, 대기열과 기간을 따로 확인했다. Flow Ultra의 일부 저우선 모드는 0크레딧이고 Magnific Plus의 일부 Kling 2.5는 Relax 대상이다. 플랜 구매비와 처리량이 있으므로 0 USD 행으로 비교하지 않았다. Flow의 Fast와 Quality는 12월 5일 퇴역 예정이며 Pro의 매일 50크레딧은 월 배정 비교에서 뺐다. Flow 크레딧 · Magnific Relax

    자료가 서로 다른 항목

    Higgsfield는 한국어 요금 화면에서 확인한 갱신가를 기본으로 쓰고 영문 공식 글의 플랜은 계산기에서 선택할 수 있게 했다. Magnific Seedance 2.5 1080p는 도움말 기준 초당 1,100크레딧인데 플랜 표의 4초 예시는 3,160이다. Kling 4.0 1080p도 일반표 초당 330과 플랜 표의 3초 840이 다르다. 서로 다른 숫자를 독립된 관측으로 기록했다. Higgsfield · Magnific 도움말 · Magnific 플랜

    Segmind의 1080p 5초는 원본 모델 예시 $3.02, Upscaled 상품 예시 $1.56이다. Runway와 WaveSpeed의 일부 4K는 출력 해상도와 가격까지 확인했다. 실제 생성 방식은 공급처 근거가 있는 행에서만 표시했다. Segmind 원본 · Segmind Upscaled

    제작에 대입할 때

    반복 제작에서는 채택 컷 비용 = 유료 생성 총액 ÷ 채택 컷 수로 비교한다. 예를 들어 $0.60 모델에서 평균 3번, $1.20 모델에서 평균 1.3번을 유료 생성하면 채택 컷당 각각 $1.80과 $1.56이다. 공급자 오류의 무료 환급과 완성됐지만 버린 유료 컷을 따로 센다. BytePlus와 Kie는 실패 과금 정책을 공개한다. BytePlus 과금 규칙 · Kie 실패 과금 규칙

    Social Flow의 대사 컷은 동일 인물의 음성 샘플 참조나 제공 오디오 입력을 먼저 확인한다. 오디오 생성 포함 가격은 그 기능의 증거가 아니다. 짧은 1080p 컷에서는 LTX A2V, 멀티모달 참조 컷에서는 Seedance·H3·HeyGen으로 각각 견적을 낼 수 있다. 한국어 대사 품질과 채택률은 실측하지 않았다. LTX · MiniMax · HeyGen

    미확인 가격과 제외 범위
    • Kling 공식 API의 4.0 요율은 720p·1080p·4K에서 각각 1·1.5·3.5 Unit/출력 초다. 구매 패키지의 USD 환산은 확인하지 못했다. Cloudflare, fal, Runway 등은 각 판매처 가격이다. Kling 개발자 가격
    • Luma API Ray 3.2의 SDR 크레딧 표는 확인했다. API 충전의 달러 환산은 확인하지 못해 웹 크레딧을 대입하지 않았다. Scenario·Hedra Play는 공개 플랜 또는 견적 경로까지 확인했다. Luma API · Scenario · Hedra
    • Pollo는 한국 표시 원화와 확인한 프로모션 설정으로 기록했다. Dreamina는 Higgsfield가 공개한 관측값이다. 세금, 카드 수수료, 기업 계약과 국가별 할인은 계산에서 제외했다. Pollo · Dreamina 비교 관측
    • OpenAI 공식 Sora API는 9월 24일 종료됐다. 일부 판매처에 모델 이름이 보이는 경우에도 공식 API 대안 목록에는 넣지 않았다. OpenAI 종료 공지
    • 자료는 공개 가격과 문서의 스냅샷이다. 유료 호출, 구매, 한국 계약 적용 여부와 실제 청구는 검증하지 않았다. 모델 표기 개수에는 버전과 판매처의 티어 이름이 포함된다.
