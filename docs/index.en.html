API keys — how far to go before stopping

The keys come in two independent groups. Stop after either one and the pipeline still runs.

Production keys. OPENAI_API_KEY draws the cover and any frame with text on it; GEMINI_API_KEY covers generated video clips, acted narration, and BGM. Strictly speaking both are optional — scene backgrounds default to on-device image_local_generate (Z-Image Turbo, Apple Silicon) and narration to on-device tts_local_generate (Supertonic 3), so a run with no keys still produces a video. What you give up without OPENAI_API_KEY is text-bearing frames (local image generation garbles Korean glyphs); without GEMINI_API_KEY you lose generated motion and music. Research keys (SERPAPI_API_KEY and the Naver pair) are optional too, and the storyboard skill falls back to WebSearch.

Platform credentials (Threads · Instagram · YouTube · Facebook) — optional. Configure them and publish posts straight to your accounts. grow-threads, grow-youtube, and grow-instagram then take over day-to-day operation on /loop — comment replies, insight watching, keyword conversations, queue refills, and posting, all inside the standing authorization you approved once at init. Skip them and everything through production works as before: produce writes the finished video plus per-platform text into data/<channel>/episodes/<topic>/output/ and you upload those files by hand. In that case the nine publish/insight tools aren't listed at all, so tools/list shows 52 tools instead of 61. Credentials are per platform, so this is not all-or-nothing, and adding a token later needs no server restart.

README.md is the source of truth for variable names, defaults, and the credential-file convention. For the order to actually do it in, see Getting started — install to first video.

Every outgoing text passes a gate. Wherever Korean text gets produced, check-style.py deterministically flags translationese, stock phrases, and assistant register; above it the adversarial reviewers (storyboard-reviewer · content-reviewer · growth-post-reviewer) read it again.
