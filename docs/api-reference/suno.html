Suno — 보컬 풀송 · 루프 BGM

Suno Inc. 는 2026-08 기준 공개 셀프서브 API 가 없다. 이 서버가 부르는 것은 sunoapi.org(Kie.ai 계열) 서드파티 REST 다. 키는 SUNO_API_KEY 이고 Gemini 키와는 다르다. 나레이션 밑 침대의 기본 경로는 그대로 Lyria(music_*)다.

1. 언제 쓰나

할 일툴키
나레이션 밑 침대 (기본)music_generate_clip 30초, 빌더가 루프GEMINI_API_KEY
길이를 초 단위로, 또는 seed 재현music_generate / music_generate_advancedGEMINI_API_KEY
나레이션 밑 침대 (Suno)suno_generate + instrumentalSUNO_API_KEY
노래가 콘텐츠suno_generateSUNO_API_KEY
무인 경로(autoproduce)는 suno_* 를 부르지 않는다. 보컬이 나레이션과 싸우고, 호출당 2~3분이 든다. 노래가 본편인 회차는 사람 경로 produce 다.

2. suno_generate

호출당 정확히 두 곡. 원격 URL 은 14일 뒤 사라지므로 폴링이 끝나는 즉시 로컬에 저장한다. 웹훅 서버가 없는 MCP stdio 환경이라 callBackUrl 은 더미(https://httpbin.org/post)를 보내고 폴링으로 끝낸다. 콜백만 실패하고 오디오 URL 이 있으면 성공으로 읽는다.

  • customMode=false — style 이나 lyrics 가 있어야 한다. prompt 만 보내면 거절한다. prompt 는 3,000자까지.
  • customMode=true — style·lyrics·negativeTags 중 하나가 있어야 한다. lyrics(5,000자)는 적힌 그대로 불리고 prompt 보다 먼저다. style 과 negativeTags 는 1,000자씩, title 은 80자까지.
  • 커스텀 모드에서만 받는 값: duration(10–360초), vocalGender, 페르소나, styleWeight·weirdnessConstraint·audioWeight(0–1), variety(0–4).

기본 모델은 V6 이고 V6_MINI 와 V6_WILD 를 고를 수 있다. 제공처는 V4·V5 계열을 기존 연동용으로만 두고 있고 이 서버는 그 모델을 거절한다. 제공처 문서에 V6 호출의 크레딧 값이 없으니(2026-11-21 확인) 호출 앞뒤로 suno_credits 를 읽는다.

3. suno_generate_sound

아무것도 제출하지 않고 거절한다. Sounds 엔드포인트는 V6 계열을 받지만(2026-11-21 확인) 끝난 사운드 태스크를 가져오는 방법이 제공처 문서에 없다. 상태 조회 엔드포인트는 Generate 와 Extend Music 만 말하고 Sounds 페이지에는 콜백 본문 예시가 없다. 생성 호출은 과금되므로 실제 사운드 태스크 하나를 받아 본 뒤에 연다. 나레이션 밑 침대는 suno_generate 에 instrumental 을 켜서 만든다.

4. 구현이 좁힌 것

  • 인증은 Bearer SUNO_API_KEY. Gemini 키로 대체하지 않는다.
  • 기본 호스트 https://api.sunoapi.org. SUNO_BASE_URL 은 같은 스펙의 미러용이고, 다른 벤더(TTAPI·EvoLink)는 헤더와 경로가 달라 여기 넣으면 안 된다.
  • 가사는 suno_generate_lyrics, 잔량은 suno_credits.
  • 키는 기동이 아니라 호출 시점에 검사한다. 키가 없어도 Lyria 는 그대로 돈다.
