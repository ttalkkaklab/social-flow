Suno — 보컬 풀송 · 루프 BGM

Suno Inc. 는 2026-08 기준 공개 셀프서브 API 가 없다. 이 서버가 부르는 것은 sunoapi.org(Kie.ai 계열) 서드파티 REST 다. 키는 SUNO_API_KEY 이고 Gemini 키와는 다르다. 나레이션 밑 침대의 기본 경로는 그대로 Lyria(music_*)다.

1. 언제 쓰나

할 일툴키
나레이션 밑 침대 (기본)music_generate_clip 30초, 빌더가 루프GEMINI_API_KEY
길이를 초 단위로, 또는 seed 재현music_generate / music_generate_advancedGEMINI_API_KEY
나레이션 밑 침대 (Suno)suno_generate_sound 루프+BPMSUNO_API_KEY
노래가 콘텐츠suno_generateSUNO_API_KEY
무인 경로(autoproduce)는 suno_* 를 부르지 않는다. 보컬이 나레이션과 싸우고, 호출당 2~3분이 든다. 노래가 본편인 회차는 사람 경로 produce 다.

2. suno_generate

호출당 정확히 두 곡. 원격 URL 은 15일 뒤 사라지므로 폴링이 끝나는 즉시 로컬에 저장한다. 웹훅 서버가 없는 MCP stdio 환경이라 callBackUrl 은 더미(https://httpbin.org/post)를 보내고 폴링으로 끝낸다. 콜백만 실패하고 오디오 URL 이 있으면 성공으로 읽는다.

  • customMode=false — prompt 만으로 가사·스타일을 모델이 정한다.
  • customMode=true + 보컬 — prompt 가 가사 그대로 불린다. style·title 필수.
  • customMode=true + instrumental=true — 보컬 없음. style·title 필수.

기본 모델 V5 (최대 8분). duration(10–360초)는 V5_5 + customMode 만 받는다. 생성은 약 12 크레딧/호출(≈ $0.06, $5/1000 팩).

3. suno_generate_sound

V5 전용 Sounds 태스크. 인트로·아웃트로 없는 루프, BPM·조성을 지정할 수 있다. 빌더가 -stream_loop -1 로 늘린다. filename 을 .wav 로 두면 48kHz 스테레오 PCM 으로 바꿔 .work/bgm.wav 에 맞춘다.

4. 구현이 좁힌 것

  • 인증은 Bearer SUNO_API_KEY. Gemini 키로 대체하지 않는다.
  • 기본 호스트 https://api.sunoapi.org. SUNO_BASE_URL 은 같은 스펙의 미러용이고, 다른 벤더(TTAPI·EvoLink)는 헤더와 경로가 달라 여기 넣으면 안 된다.
  • 가사는 suno_generate_lyrics, 잔량은 suno_credits.
  • 키는 기동이 아니라 호출 시점에 검사한다. 키가 없어도 Lyria 는 그대로 돈다.
