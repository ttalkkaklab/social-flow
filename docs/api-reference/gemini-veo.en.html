Veo 3.1 — video generation

An async long-running operation API that makes video with native audio. A single generateVideos call splits into four modes depending on the input combination (image · video · referenceImages).

These constraints get caught at the zod stage, before the call, for cost reasons. A Veo call takes 1–6 minutes and the wait is spent even when it fails. If the server rejects the combination up front, the model can immediately call again with corrected arguments.
The veo-3.0 and veo-2.0 families were shut down on 2026-06-30. Even if you see an ID like veo-3.0-generate-001 in other docs or examples, the Gemini API won't call it.

// extension — as in the official sample, don't pass durationSeconds or aspectRatio
const operation = await genai.models.generateVideos({
  model: 'veo-3.1-generate-preview',
  prompt: 'the camera slowly pulls back to reveal the wider scene',
  video: { videoBytes: base64, mimeType: 'video/mp4' },
  config: { numberOfVideos: 1, resolution: '720p' },
});
The Added Duration in a veo_extension response is the length added (+7s), not the total. Accumulated over 20 calls that's the original 8s plus 140s.

4. Async polling and download

Generation doesn't finish immediately. Poll the operation.name the SDK returned over REST.

GET https://generativelanguage.googleapis.com/v1beta/{operation.name}
x-goog-api-key: {API_KEY}
The key goes in the x-goog-api-key header, not a ?key= query — URLs can be echoed into logs and error messages, which makes them a leak surface, while the header has no such path. Measured 2026-07-29: header auth confirmed to clear the unregistered-caller gate.
Response fieldMeaning
doneWhether it finished
error.messageWhy generation failed
response.generateVideoResponse.generatedSamples[].video.uriResult video URI (current shape)
response.generatedVideos[].video.uriLegacy shape — checked too, for compatibility
response.generateVideoResponse.raiMediaFilteredReasons[]Why the responsible-AI filter caught it. If it isn't empty, there's no result

Downloading the video URI uses the same header auth. The server polls at 10-second intervals up to 60 times (= 10 minutes), and past that fails with Video generation timed out (10 minutes).

The RAI filter arrives as done: true plus an empty result. Without checking raiMediaFilteredReasons first, it turns into a vague "there's no video" error and the model retries with the same prompt — a retry that's certain to be caught again and burns the wait for nothing.

Every output carries an invisible SynthID watermark.

Official limits that bite in operation (rechecked 2026-08-15)

LimitDetail
Result retentionDeleted from the server after 2 days. Harmless for this server since it saves locally right away, but extending a clip days later needs the local file
Billing when blockedIf a safety filter or audio processing blocks generation, you aren't charged
Latency11 seconds minimum, 6 minutes at peak. This server's 10-minute polling cap has room
LanguageOnly English is fully supported. Other languages aren't evaluated, so results can differ
Multiple video referenceThere's no feature for referencing or reasoning over several videos. Trying it degrades quality
RegionAccounts in the EU, UK, Switzerland, and MENA get personGeneration narrowed to allow_adult

5. Prompt rules

  • Audio is generated natively. Wrap dialogue in double quotes and spell out sound effects ("engine roaring") and ambience in the prompt.
  • English prompts are more stable.
  • For short-form, aspectRatio: '9:16' is the default choice.
  • Cost lever: lite (1/8) for drafts and tests, fast (1/4) for mid-quality, the base model only for the final cut.
