전 모델 24fps 고정이고 비율은 16:9 · 9:16 · 4:3 · 3:4 · 1:1 · 21:9 · adaptive 를 모두 받는다. seedance-1-0-pro-fast 만 첫 프레임 전용이라 첫+끝 프레임 보간을 못 한다.

활성화 관문 칸은 돈 관문만 가리킨다 — 2.x 는 잔액 $30 초과 또는 리소스팩이 있어야 열리고, 1.5 pro·1.0 계열에는 그 조건이 없다. 다만 “없음”이 “바로 쓸 수 있다”는 뜻은 아니다. 어느 모델이든 콘솔 Model activation 에서 먼저 켜야 하고, 안 켠 모델을 부르면 태스크 생성이 ModelNotOpen 으로 실패한다(과금 없음). 첫 활성화 때는 TOS·VPC·ML 플랫폼 교차 서비스 권한 동의도 함께 요구한다.

기본값이 seedance-1-5-pro-251215 인 이유는 셋이다 — 오늘 1080p 를 낼 수 있고, 실사 인물 입력을 받으며, 잔액 관문이 없다. 이 파이프라인의 커버 배경이 실사 인물 PNG 라 2.x 로 보내면 회차가 통째로 막힌다.
2.5 의 1080p 는 2026-08-17(UTC+8)에 열렸다. 구현은 아직 따라가지 않았다. seedance-client.ts 능력표의 dreamina-seedance-2-5-260628.resolutions 는 2026-08-18 현재 480p·720p 둘뿐이라, 2.5 에 1080p 를 요청하면 API 에 닿기 전에 스키마가 거부한다. 능력표에 '1080p' 를 더해야 풀린다.

2. REST 계약 — 만들고 폴링한다

생성은 비동기다. POST 가 태스크 ID 만 돌려주고, GET 으로 succeeded 가 될 때까지 폴링한 뒤 결과 URL 에서 mp4 를 내려받는다.

POST https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks
Authorization: Bearer $ARK_API_KEY

{ "model": "seedance-1-5-pro-251215",
  "content": [ { "type": "text", "text": "..." },
               { "type": "image_url", "image_url": { "url": "data:image/png;base64,..." },
                 "role": "first_frame" } ],
  "ratio": "adaptive", "resolution": "1080p", "duration": 5,
  "generate_audio": false, "watermark": false }
→ { "id": "cgt-2026..." }

GET .../contents/generations/tasks/cgt-2026...
→ { "status": "succeeded",
    "content": { "video_url": "https://...tos-ap-southeast-1.volces.com/..." },
    "usage": { "completion_tokens": 244800 },
    "duration": 5, "ratio": "9:16", "resolution": "1080p", "framespersecond": 24 }

주소 앞부분은 ARK_BASE_URL 이 정하고 기본값이 https://ark.ap-southeast.bytepluses.com/api/v3 다. 영상 모델은 ap-southeast-1(싱가포르)에만 있으므로 평소에는 그대로 둔다 — 중국 본토 Ark(volcengine) 같은 다른 리전을 쓸 때만 바꾼다. 인증은 ARK_API_KEY 이고, 콘솔이 따로 발급하는 ark- 로 시작하는 API Key 다(서명용 AccessKeyId/SecretAccessKey 가 아니다).

상태의미
queued / running계속 폴링한다
succeededcontent.video_url 에서 즉시 내려받는다
failederror.code · error.message 에 사유. 실패 건은 과금되지 않는다
expiredexecution_expires_after(기본 48시간)를 넘겨 종료
cancelled큐 상태에서 취소됨 — 24시간 뒤 자동 삭제
결과 URL 은 24시간짜리다(2.5 는 다운로드 100회 제한도 걸린다). 작업 조회도 최근 7일치만 된다. 이 서버는 폴링이 끝나는 즉시 로컬 mp4 로 저장하고 경로만 반환한다 — URL 을 호출자에게 돌려주면 하루 뒤 죽은 링크가 된다.

3. 요청 파라미터

필드값비고
content[]text · image_url · video_url · audio_url이미지는 공개 URL 또는 base64 data URI. 영상·오디오 참조는 공개 URL 만 받는다(base64 불가)
content[].rolefirst_frame · last_frame · reference_image세 시나리오는 배타적이라 섞을 수 없다
ratio7종 + adaptive이미지 입력에서 비율이 다르면 서버가 중앙 기준으로 잘라낸다
resolution480p ~ 4k모델별로 다름(§1). 4K 는 10bit H.265 라 재생 호환성 주의
duration정수 초, 또는 -1(자동)모델별 범위가 다름. 과금이 이 값에 정비례한다
generate_audio기본 true1.0 계열은 무음 전용이라 true 를 거절한다. 1.5 pro 는 켜면 단가가 정확히 2배
seed · camera_fixed1.5 pro · 1.0 계열 전용2.x 는 둘 다 없다 — 카메라 고정은 프롬프트로 지시한다
watermark기본 falsetrue 면 우하단에 "AI Generated" 가 박힌다
frames25 + 4n소수점 초 길이용. 1.0 pro·fast 전용이며 duration 보다 우선한다
callback_url웹훅 주소폴링 대신 상태 변화를 받는다. 이 서버는 폴링을 쓴다(로컬 프로세스라 수신할 주소가 없다)
service_tierdefault · flexflex 는 값이 절반인 오프라인 추론 — 1.x 만 지원한다

입력 이미지 제약

포맷 jpeg·png·webp·bmp·tiff·gif, 비율 0.4~2.5, 변 300~6000px, 장당 30MB 이하, 요청 본문 합계 64MB 이하. 프롬프트는 500자(한글)·1,000단어(영어) 이하를 권한다. 한국어 프롬프트를 공식 지원하는 모델은 2.5 뿐이고, 2.0 계열은 영어·스페인어·인도네시아어·포르투갈어·일본어, 1.x 는 영어다.

4. 과금 — 토큰 산식과 실비

토큰 = (입력 영상 길이 + 출력 영상 길이) × 출력 가로 × 출력 세로 × fps / 1024
요금 = 모델·해상도별 토큰 단가 × 토큰

가로·세로의 곱만 쓰므로 9:16 은 16:9 와 값이 같다(720p 5초 = 102,960 토큰). 실제 청구는 응답의 usage.completion_tokens 가 정본이고, 생성 실패·검열 차단 건은 청구되지 않는다.

영상 모델에는 무료 쿼터가 없다. ModelArk 무료 체험분은 LLM·비전 모델용이고, 모델 목록의 무료 쿼터 칸은 3D·임베딩 모델에만 붙어 있다. 검색에 나오는 "Seedance 200만 토큰 무료"는 1.0 시절 블로그 문구다.
