SUNOAPI.ORG

Suno — sung full songs · loop BGM

Suno Inc. has no public self-serve API as of 2026-08. This server talks to sunoapi.org (Kie.ai family), a third-party REST wrapper. The key is SUNO_API_KEY, not the Gemini key. The default narration-under bed is still Lyria (music_*).

The unattended path (autoproduce) never calls suno_*. Vocals fight the voiceover, and each call takes 2–3 minutes. An episode where the song is the piece goes through the human produce path.

2. suno_generate

Exactly two tracks per call. Remote URLs expire after 14 days, so files are saved locally as soon as polling finishes. MCP stdio has no webhook server, so callBackUrl is a dummy (https://httpbin.org/post) and we finish by polling. A callback exception with an audio URL present is treated as success.

  • customMode=false — needs style or lyrics; a prompt alone is refused. prompt is at most 3,000 characters.
  • customMode=true — needs style, lyrics or negativeTags. lyrics (5,000 characters) is sung as written and comes before prompt. style and negativeTags take 1,000 characters each, title 80.
  • Custom mode only: duration (10–360s), vocalGender, a persona, styleWeight · weirdnessConstraint · audioWeight (0–1) and variety (0–4).

The default model is V6; V6_MINI and V6_WILD are the other two. The provider keeps the V4 and V5 families only for old integrations, and this server refuses them. The provider's pages give no credit cost for a V6 call (read 2026-11-21), so read suno_credits before and after.

3. suno_generate_sound

Refused before anything is submitted. The Sounds endpoint takes the V6 family (read 2026-11-21), but the provider's pages say nothing about fetching a finished sounds task: the status endpoint names Generate and Extend Music only, and the Sounds page shows no callback payload. A create call is billed, so the tool opens after one real sounds task has been fetched. For a bed under narration, use suno_generate with instrumental.

4. What this implementation narrows

  • Auth is Bearer SUNO_API_KEY. The Gemini key is not a substitute.
  • Default host https://api.sunoapi.org. SUNO_BASE_URL is for a same-spec mirror — other vendors (TTAPI, EvoLink) use different headers and paths and must not be pointed here.
  • Lyrics only: suno_generate_lyrics. Remaining credits: suno_credits.
  • The key is checked at call time, not startup. Lyria keeps working without it.
