SUNOAPI.ORG

Suno — sung full songs · loop BGM

Suno Inc. has no public self-serve API as of 2026-08. This server talks to sunoapi.org (Kie.ai family), a third-party REST wrapper. The key is SUNO_API_KEY, not the Gemini key. The default narration-under bed is still Lyria (music_*).

The unattended path (autoproduce) never calls suno_*. Vocals fight the voiceover, and each call takes 2–3 minutes. An episode where the song is the piece goes through the human produce path.

2. suno_generate

Exactly two tracks per call. Remote URLs expire after 15 days, so files are saved locally as soon as polling finishes. MCP stdio has no webhook server, so callBackUrl is a dummy (https://httpbin.org/post) and we finish by polling. A callback exception with an audio URL present is treated as success.

  • customMode=false — the model writes lyrics and style from prompt alone.
  • customMode=true with vocals — prompt is sung as the lyrics. style and title required.
  • customMode=true + instrumental=true — no vocals. style and title required.

Default model V5 (up to 8 minutes). duration (10–360s) is accepted only on V5_5 + customMode. Generate costs about 12 credits/call (≈ $0.06 at the $5/1000 pack).

3. suno_generate_sound

V5-only Sounds task. A loop without intro/outro, with optional BPM and key. The builder stretches it with -stream_loop -1. Set filename to .wav to transcode to 48kHz stereo PCM for .work/bgm.wav.

4. What this implementation narrows

  • Auth is Bearer SUNO_API_KEY. The Gemini key is not a substitute.
  • Default host https://api.sunoapi.org. SUNO_BASE_URL is for a same-spec mirror — other vendors (TTAPI, EvoLink) use different headers and paths and must not be pointed here.
  • Lyrics only: suno_generate_lyrics. Remaining credits: suno_credits.
  • The key is checked at call time, not startup. Lyria keeps working without it.
