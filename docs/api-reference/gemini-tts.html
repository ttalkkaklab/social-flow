Gemini TTS — 음성 합성

텍스트를 음성으로 바꾸는 generateContent 변형. 별도 TTS 엔드포인트가 아니라 responseModalities: ['AUDIO']와 speechConfig를 얹은 일반 생성 호출이라, LLM의 비결정성이 그대로 따라온다.

1. 모델

모델 ID특징스트리밍무료 티어

gemini-2.5-pro-preview-tts고품질. flash가 반복 실패하는 대본의 폴백미지원없음

실측: flash → pro 폴백은 실재하는 실패 모드다. 짧은 2인 대화 대본에서 gemini-2.5-flash-preview-tts가 "Model tried to generate text, but it should only be used for TTS" 400을 반복 반환하다가, 모델만 gemini-2.5-pro-preview-tts로 바꾸면 한 번에 통과했다(화자 이름의 한/영 여부와 무관). 서버는 3회 자동 재시도 후 이 폴백을 에러 메시지에 안내한다.

3. 요청 구조

단일 화자

genai.models.generateContent({
  model: 'gemini-2.5-flash-preview-tts',
  contents: [{ role: 'user', parts: [{ text: contentText }] }],
  config: {
    responseModalities: ['AUDIO'],
    speechConfig: { voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Kore' } } },
    temperature: 0.4,
  },
});

2인 화자

speechConfig: {
  multiSpeakerVoiceConfig: {
    speakerVoiceConfigs: [
      { speaker: '진행자', voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Kore' } } },
      { speaker: '패널',   voiceConfig: { prebuiltVoiceConfig: { voiceName: 'Puck' } } },
    ],
  },
}

대본은 진행자: 안녕하세요\n패널: 반갑습니다처럼 화자 이름을 접두어로 붙인다. 이름은 speakerVoiceConfigs의 speaker와 정확히 같아야 한다.

스타일 지시

언어·톤·속도를 요청 필드로 받지 않는다. 프롬프트 본문으로 지시한다.

Synthesize the following transcript as speech.
Director's Notes — Style: 차분하고 신뢰감 있게, 약간 느리게
--- TRANSCRIPT BEGINS ---
<대본>
라벨 없는 스타일: "본문" 합성은 두 가지로 실패한다 — 분류기가 오거절(PROHIBITED_CONTENT)하거나, 모델이 지시문 자체를 소리내어 읽는다. 위처럼 합성 preamble과 대본 시작 라벨을 명시하면 둘 다 피할 수 있다(buildStyledPrompt).

4. 출력 포맷

항목값
응답 위치candidates[0].content.parts[].inlineData.data (base64)
MIMEaudio/L16;codec=pcm;rate=24000
컨테이너없음 — 원시 PCM
샘플레이트24,000 Hz (MIME의 rate= 파라미터가 정본)
채널 · 비트심도1 (모노) · 16-bit

컨테이너가 없으므로 그대로 저장하면 어떤 플레이어도 재생하지 못한다. 서버가 44바이트 RIFF/WAVE 헤더를 씌워 .wav로 저장한다(media-utils.pcmToWav). 샘플레이트는 상수가 아니라 응답 MIME에서 파싱한다 — 공급사가 값을 바꿔도 피치가 틀어지지 않는다.

5. 제약과 실패 모드

제약값대응
세션 컨텍스트32k 토큰입력을 16,000자로 제한(CJK ≈ 1~2 토큰/자 보수 환산)
입출력 형태텍스트 입력 → 오디오 출력 전용—
지원 언어90여 종 (BCP-47 표). 번체 중국어 zh-TW 포함언어는 요청 필드가 아니라 입력 텍스트에서 자동 감지된다
화자 수최대 2인스키마 maxItems: 2
긴 출력 품질수 분을 넘기면 톤·속도가 드리프트컷 단위 분할 합성 권장
무작위 텍스트 토큰오디오 대신 텍스트가 반환되며 500/400이 뜬다3회 자동 재시도(400·800·1200ms) 후 pro 폴백 안내
프롬프트 분류기 오거절모호한 지시문이 거절을 유발합성 preamble 고정(위 §3)
같은 영상 안의 컷은 voiceName·stylePrompt·temperature를 바이트 단위로 동일하게 유지해야 한다. LLM 기반이라 지시문의 사소한 표현 변경도 재해석되어 내레이터 목소리가 컷마다 흔들린다. 이 서버가 공급사 기본값(1.0) 대신 temperature: 0.4를 기본으로 두는 이유다.

6. 구현 대조표

항목공식 계약social-flow 구현차이의 이유
입력 길이32k 토큰16,000자 하드 상한토큰↔문자 환산의 보수적 마진. 초과 시 "대본을 나누라"는 실행 가능한 에러
temperature문서에 명시 없음 (generateContent 공통 필드로 동작)기본 0.4, 범위 0–2회차 간 보이스 일관성. 공급사 기본 1.0은 내레이션에 과하다
재시도문서가 재시도를 권고3회 · 선형 백오프 · 마지막에 모델 교체 힌트—
화자 수최대 2minItems: 1, maxItems: 21인도 multiSpeakerVoiceConfig로 유효
출력 저장base64 PCM 반환WAV로 감싸 로컬 저장 후 경로만 반환수 MB base64는 컨텍스트를 태우는데 모델은 오디오를 평가하지 못한다
파일명—경로 분리자·.. 거부 + 오디오 확장자 화이트리스트path.join이 ../를 정규화해 없애므로 조립 전에 막아야 한다
