API REFERENCE

social-flow가 호출하는 전체 API

내부 MCP 서버(server/src)가 실제로 호출하는 외부 API 12종의 공식 계약을 정리한 레퍼런스다. 각 문서는 공식 문서가 말하는 것과 이 저장소의 구현이 실제로 하는 것을 나란히 적어, 둘이 어긋나는 지점을 바로 볼 수 있게 했다. 이미지·음성은 네트워크를 타지 않는 온디바이스 엔진 2종이 기본 경로이며 그쪽은 호출할 외부 계약이 없다.

API 문서

MCP 툴 스펙 & 베스트 프랙티스

Tool 정의 필드 전체(title·annotations·outputSchema), CallToolResult 계약, 에러 2계층, 그리고 툴 작성 원칙 7가지와 이 저장소의 평가 루브릭.

프로토콜 · 전 툴 공통

Gemini TTS

모델 3종, 프리빌트 음성 30종, 32k 토큰 세션 한도, 단일·2인 화자 설정, PCM 24kHz 모노 출력.

tts_generate · tts_multi_speaker · tts_list_voices

Google Veo 3.1

모델 3종의 해상도·길이·비율 교차 제약, 연장(+7초·최대 20회)과 참조 이미지(최대 3장·8초 고정), long-running operation 폴링.

veo_text2video · veo_img2video · veo_extension · veo_reference

Veo 인물·참조 정책

성인 얼굴은 통과하고 아이 얼굴은 막히는 personGeneration 계약, 자산 등록소가 없는 이유, 3.1 에서 닫힌 화풍 참조와 구도를 정하는 첫·끝 프레임.

personGeneration · referenceType asset / style · lastFrame

ByteDance Seedance

모델 7종의 능력 차이(해상도·길이·참조 이미지·음성·seed), 태스크 생성 → 폴링 → 24시간 URL 회수, 토큰 과금 산식과 실사 얼굴 입력 거부.

seedance_text2video · seedance_img2video · seedance_reference

Seedance 인물·자산 정책

2.x 의 얼굴 입력 거부와 우회로 셋(신뢰 출력물 30일·프리셋 디지털 캐릭터·권리 확보 실인물), 자산 등록 절차와 규격, 참조 이미지를 콘티처럼 쓰면 깨지는 이유.

asset:// · reference_image · first_frame / last_frame

Google Lyria

성격이 다른 두 API — Lyria 3 Clip(Interactions·30초 고정·MP3)과 Lyria RealTime(WebSocket·PCM 48kHz·설정 12종).

music_generate_clip · music_generate · music_generate_advanced · music_list_options

OpenAI Images

GPT Image 4종의 파라미터 지원 행렬, gpt-image-2 임의 해상도 제약(16 배수·1:3~3:1·픽셀 상하한), 편집 전용 파라미터.

gpt_image_text2img · gpt_image_img2img

온디바이스 엔진 (Z-Image · Supertonic)

외부 계약이 없는 두 툴. Z-Image Turbo 는 mflux/MLX 로 돌아 1024²가 9스텝에 149~210초, 1088×1920 이 462초다(M4 Max 실측). Supertonic 은 CPU 만 쓰고 44.1kHz wav 를 내며, 둘 다 키·과금·네트워크가 없다.

image_local_generate · tts_local_generate

SerpApi

google · google_news · naver · google_images 네 엔진의 파라미터와 응답 구조, 엔진별로 다른 정렬 값 체계, 문서와 어긋나는 실제 응답 키, 쿼터와 과금 규칙.

serp_web_search · serp_news_search · serp_naver_search · serp_image_search

Naver 검색 Open API

8개 엔드포인트(news·blog·webkr·cafearticle·kin·image·encyc·local), 타입별로 다른 정렬·페이징 제약, 종료된 API 5종, 일 25,000회 쿼터.

naver_search

공공데이터포털

무인증 3경로(검색·상세·파일 다운로드)와 인증 2경로(odcloud·표준 오픈API), 활용신청 함정, 에러 코드표.

datago_search · datago_detail · datago_file_download · datago_file_fetch · datago_api_call

Meta Graph (Threads · IG · FB)

컨테이너-후-게시 2단계 흐름, 플랫폼별 길이·미디어 제약, 댓글 능력 비대칭표, 게시 쿼터, 그리고 성장 루프가 읽는 Threads·Instagram 인사이트 계약.

threads_publish · instagram_publish · facebook_publish · facebook_comment · sns_comment_* · threads_insights · threads_search · instagram_insights

YouTube Data API v3

resumable 업로드 2단계, 2026년 개편된 Video Uploads 쿼터 버킷, categoryId, 썸네일 설정과 인증 요건, Analytics API 를 따로 켜야 하는 이유와 2~3일 지연.

youtube_publish · youtube_insights · sns_account_check

이 문서를 만든 방법

  • 1차 출처는 공급사 공식 문서다. 각 페이지 상단에 원문 링크를 달았다.
  • 공식 문서가 침묵하거나 실제와 다른 항목은 SDK 타입 정의(node_modules/openai/resources/images.d.ts, node_modules/@google/genai/dist/genai.d.ts)와 실호출 실측으로 확정했다. 그런 항목은 페이지에 근거를 명시했다.
  • 실측으로 공식 문서를 뒤집은 사례가 하나 있다 — Lyria RealTime의 apiVersion.
  • 구현이 공식 계약보다 좁게 잡은 값(예: naver_search의 display 상한 30 vs API 100)은 결함이 아니라 LLM 컨텍스트 보호를 위한 의도된 설계이며, 각 표에 "구현" 열로 구분해 적었다.
