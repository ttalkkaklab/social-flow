1. 모델과 수명

모델위치수명
gpt-image-2 기본값최신 · 추론 기반. 사진 사실감과 지시 준수가 가장 강하고, 이미지 안 텍스트 렌더링이 안정적이다—
gpt-image-1.5품질/비용 중간2026-12-01 셧다운
gpt-image-1이전 세대2026-10-23 셧다운
gpt-image-1-mini저가·저품질2026-12-01 셧다운

dall-e-2·dall-e-3는 2026-05-12 셧다운을 마쳤다. 예정된 EOL이 모두 지나면 Images API에 남는 모델은 gpt-image-2 하나다.

투명 배경은 EOL과 함께 사라진다. background: "transparent"는 gpt-image-2가 지원하지 않고, 지원하는 gpt-image-1/1.5는 2026년 안에 종료된다. 로고·오버레이 소재는 후처리(배경 제거)를 전제로 설계해야 한다.

input_fidelity를 gpt-image-2에 보내면 에러다. "무시"가 아니라 요청 자체가 실패한다. gpt-image-2는 입력 이미지를 항상 high fidelity로 처리하므로 파라미터를 생략하는 것이 정답이며, 이 서버는 스키마 단계에서 조합을 미리 거부한다.

3. size — 임의 해상도 제약

프리셋 (전 모델 공통)

auto · 1024x1024 · 1536x1024(가로) · 1024x1536(세로)

임의 해상도 WIDTHxHEIGHT — gpt-image-2 전용

제약값
가로·세로둘 다 16의 배수
가로세로비1:3 ~ 3:1
최대 변3,840px (최대 해상도 3840×2160)
총 픽셀655,360 ~ 8,294,400
실험적 구간2560×1440 초과는 실험적
쇼트폼 9:16은 1088x1920. 1080×1920은 1080이 16의 배수가 아니라 거부되므로 1088을 쓴다(1088 = 16×68, 1920 = 16×120, 총 2,088,960px, 비율 0.567 → 제약 통과).

이 서버는 네 제약을 각각 검사해 위반 항목을 모두 모아 한 번에 알린다 — 한 번에 하나씩 알리면 모델이 크기를 여러 번 고쳐 쏘게 된다.

커스텀 해상도 "1080x1921" 제약 위반: 가로·세로는 16의 배수여야 합니다

4. 편집 전용 계약 (/v1/images/edits)

항목계약
imagepng/webp/jpg, 각 50MB 미만, 최대 16장. 여러 장을 주면 합성 레퍼런스로 쓰인다
mask알파 채널이 있는 PNG, 4MB 미만, 첫 번째 이미지와 같은 크기. 완전 투명한 픽셀이 다시 그릴 영역이며, 여러 장을 줘도 마스크는 첫 장에만 적용된다
모델 기본값API 기본은 gpt-image-1.5 (이 서버는 gpt-image-2로 고정)

편집이 강한 경우: 마스크 인페인팅, 여러 레퍼런스 합성, 얼굴·로고 같은 미세 디테일 보존. 반대로 맨바닥에서 만드는 생성은 gpt_image_text2img가 맞다.

5. 응답

{ "data": [ { "b64_json": "…", "revised_prompt": "…" } ] }
  • GPT Image 계열은 항상 base64다 — URL 응답은 없다.
  • revised_prompt는 모델이 실제로 사용한 재작성 프롬프트다. 결과가 의도와 다를 때 원인 추적에 쓴다.
  • 응답 MIME은 요청한 output_format을 따른다(편집 경로도 동일).

6. 구현 대조표

항목공식 계약social-flow 구현
노출 모델GPT Image 4종 + dall-e 계열GPT Image 4종만 (dall-e는 셧다운 완료)
기본 모델generations는 dall-e-2, edits는 gpt-image-1.5둘 다 gpt-image-2로 명시 — 기본값 상속은 예측 불가능하다
n1–101 고정 (미노출) — 쇼트폼은 컷 단위 1장이 기본이고 N장은 비용이 N배다
모델별 파라미터 제약문서에 산문 서술, 위반 시 런타임 에러superRefine으로 호출 전 거부 (size·background·input_fidelity 3계열)
반환 형태base64MCP image 블록 + 요약 텍스트. savePath 지정 시 파일로도 저장
savePath—.. 거부 + 이미지 확장자 화이트리스트, 부모 디렉토리 자동 생성
output_compression·moderation·stream지원미노출 — 파이프라인에서 조정할 일이 없다
이미지만 base64를 컨텍스트로 돌려주는 유일한 생성 툴이다. 모델이 결과를 눈으로 보고 재생성 여부를 판단해야 하기 때문이다. 영상·음성·음악은 모델이 어차피 직접 평가하지 못하므로 경로만 반환한다.
