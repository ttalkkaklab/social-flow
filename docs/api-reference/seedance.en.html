Seedance — video generation

The Dreamina Seedance 2.x video engine. An async REST API where you create a task and poll it — it takes 4–30 seconds in 1-second steps and bills only for the length you ask for. In exchange, it rejects real-face inputs and the models differ widely in what they can do. Seedance 1.x left the plugin on 2026-10-31 because it takes no voice reference.

2. REST contract — create, then poll

Generation is async. POST returns nothing but a task ID; you poll with GET until succeeded, then download the mp4 from the result URL.

POST https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks
Authorization: Bearer $ARK_API_KEY

{ "model": "dreamina-seedance-2-0-260128",
  "content": [ { "type": "text", "text": "..." },
               { "type": "image_url", "image_url": { "url": "data:image/png;base64,..." },
                 "role": "first_frame" } ],
  "ratio": "adaptive", "resolution": "1080p", "duration": 5,
  "generate_audio": false, "watermark": false }
→ { "id": "cgt-2026..." }

GET .../contents/generations/tasks/cgt-2026...
→ { "status": "succeeded",
    "content": { "video_url": "https://...tos-ap-southeast-1.volces.com/..." },
    "usage": { "completion_tokens": 244800 },
    "duration": 5, "ratio": "9:16", "resolution": "1080p", "framespersecond": 24 }

The address prefix comes from ARK_BASE_URL, which defaults to https://ark.ap-southeast.bytepluses.com/api/v3. The video models exist only in ap-southeast-1 (Singapore), so normally leave it alone — change it only for another region, such as mainland-China Ark (volcengine). Auth is ARK_API_KEY, the API Key the console issues separately, starting with ark- (not the signing AccessKeyId/SecretAccessKey).

StatusMeaning
queued / runningKeep polling
succeededDownload from content.video_url right away
failedReason in error.code · error.message. Failed runs aren't billed
expiredEnded after passing execution_expires_after (48 hours by default)
cancelledCancelled while queued — auto-deleted after 24 hours
Result URLs last 24 hours (2.5 adds a 100-download cap). Task lookup only reaches back 7 days. This server saves the mp4 locally the moment polling ends and returns only the path — hand the URL to the caller and it's a dead link a day later.

Input image limits

Formats jpeg·png·webp·bmp·tiff·gif, ratio 0.4–2.5, edges 300–6000px, 30MB per image, 64MB total request body. Prompts should stay under 500 characters (Korean) or 1,000 words (English). 2.5 is the only model with official Korean prompt support; the 2.0 family takes English, Spanish, Indonesian, Portuguese, and Japanese.

4. Billing — the token formula and real costs

tokens = (input video length + output video length) × output width × output height × fps / 1024
price  = per-model, per-resolution token rate × tokens

Only the product of width and height counts, so 9:16 comes out the same as 16:9 (720p 5s = 102,960 tokens). The bill follows usage.completion_tokens in the response, and generations that fail or get blocked by moderation aren't charged.

Three temporary discounts (not folded into the list prices — they'd quietly go wrong once they end): 2.5 at 1080p is 72% of list (through ~2026-09-17), 2.0 mini 40% (through ~2026-09-07), 2.0 fast 75% (through ~2026-09-07).
Video models have no free quota. The ModelArk free trial credit is for LLM and vision models, and the free-quota column in the model list is attached only to 3D and embedding models. The "2 million free Seedance tokens" that turns up in search results is 1.0-era blog copy.

The source of truth for which engine to use when is skills/produce/references/video-model-selection.md. In short, a spoken cut goes to an adapter with a voice lane — on Seedance, seedance_reference takes a character's voice sample (the reference lane). seedance_text2video and seedance_img2video have no voice lane, so video_plan refuses a spoken cut there with voice_lane_required. A cut that lays narration over a non-speaking picture can use any adapter.
