Seedance — video generation

This server's second video engine. An async REST API where you create a task and poll it — unlike Veo it takes 2–30 seconds in 1-second steps and bills only for the length you ask for. In exchange, real-face inputs are restricted and the models differ widely in what they can do.

Every model is fixed at 24fps and accepts all of 16:9 · 9:16 · 4:3 · 3:4 · 1:1 · 21:9 · adaptive. Only seedance-1-0-pro-fast is first-frame only, so it can't interpolate first+last frames.

The activation-gate column flags the money gate only — 2.x opens with an account balance over $30 or a resource pack, and 1.5 pro and the 1.0 family have no such condition. But "None" doesn't mean "works out of the box." Every model has to be switched on first under Model activation in the console, and calling one that isn't enabled fails task creation with ModelNotOpen (no charge). First-time activation also asks for TOS, VPC, and ML platform cross-service authorization.

seedance-1-5-pro-251215 is the default for three reasons — it can output 1080p today, it accepts photoreal person inputs, and it has no balance gate. This pipeline's cover backgrounds are photoreal person PNGs, so sending them to 2.x blocks the whole episode.
2.5's 1080p opened on 2026-08-17 (UTC+8). The implementation hasn't followed yet. As of 2026-08-18, dreamina-seedance-2-5-260628.resolutions in the seedance-client.ts capability table still holds only 480p and 720p, so asking 2.5 for 1080p is rejected by the schema before it reaches the API. Adding '1080p' to the capability table unblocks it.

2. REST contract — create, then poll

Generation is async. POST returns nothing but a task ID; you poll with GET until succeeded, then download the mp4 from the result URL.

POST https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks
Authorization: Bearer $ARK_API_KEY

{ "model": "seedance-1-5-pro-251215",
  "content": [ { "type": "text", "text": "..." },
               { "type": "image_url", "image_url": { "url": "data:image/png;base64,..." },
                 "role": "first_frame" } ],
  "ratio": "adaptive", "resolution": "1080p", "duration": 5,
  "generate_audio": false, "watermark": false }
→ { "id": "cgt-2026..." }

GET .../contents/generations/tasks/cgt-2026...
→ { "status": "succeeded",
    "content": { "video_url": "https://...tos-ap-southeast-1.volces.com/..." },
    "usage": { "completion_tokens": 244800 },
    "duration": 5, "ratio": "9:16", "resolution": "1080p", "framespersecond": 24 }

The address prefix comes from ARK_BASE_URL, which defaults to https://ark.ap-southeast.bytepluses.com/api/v3. The video models exist only in ap-southeast-1 (Singapore), so normally leave it alone — change it only for another region, such as mainland-China Ark (volcengine). Auth is ARK_API_KEY, the API Key the console issues separately, starting with ark- (not the signing AccessKeyId/SecretAccessKey).

StatusMeaning
queued / runningKeep polling
succeededDownload from content.video_url right away
failedReason in error.code · error.message. Failed runs aren't billed
expiredEnded after passing execution_expires_after (48 hours by default)
cancelledCancelled while queued — auto-deleted after 24 hours
Result URLs last 24 hours (2.5 adds a 100-download cap). Task lookup only reaches back 7 days. This server saves the mp4 locally the moment polling ends and returns only the path — hand the URL to the caller and it's a dead link a day later.

service_tierdefault · flexflex is half-price offline inference — 1.x only

Input image limits

Formats jpeg·png·webp·bmp·tiff·gif, ratio 0.4–2.5, edges 300–6000px, 30MB per image, 64MB total request body. Prompts should stay under 500 characters (Korean) or 1,000 words (English). 2.5 is the only model with official Korean prompt support; the 2.0 family takes English, Spanish, Indonesian, Portuguese, and Japanese, and 1.x takes English.

4. Billing — the token formula and real costs

tokens = (input video length + output video length) × output width × output height × fps / 1024
price  = per-model, per-resolution token rate × tokens

Only the product of width and height counts, so 9:16 comes out the same as 16:9 (720p 5s = 102,960 tokens). The bill follows usage.completion_tokens in the response, and generations that fail or get blocked by moderation aren't charged.

Video models have no free quota. The ModelArk free trial credit is for LLM and vision models, and the free-quota column in the model list is attached only to 3D and embedding models. The "2 million free Seedance tokens" that turns up in search results is 1.0-era blog copy.

The source of truth for which engine to use when is skills/produce/references/video-model-selection.md. In short, Veo for stretches that use sound, Seedance for stretches that throw it away — b-roll slots use the clip's own audio (produce absolute rule 9) so they stay on Veo, and Seedance's place is the motion background (visual.video), where the builder lays down the video track alone.
