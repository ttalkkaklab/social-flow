ElevenLabs v4 음성 API

이 플러그인은 eleven_v4로 한 사람의 음성과 여러 사람의 대화를 생성합니다. 두 도구 모두 Text to Dialogue를 호출합니다. 이 안내서는 현재 구현을 설명하며 과거 v2/v3 실측 자료와 구분합니다.

모델 · 요청 · 출력 · 시간 정보 · 목소리 · 사용량 · 검증

모델과 한도

지원 모델은 eleven_v4입니다. eleven_v4_turbo는 실시간 WebSocket 모델이므로 현재 파일 생성 도구에서는 지원하지 않습니다. 오류가 나도 저장된 목소리나 모델을 자동으로 바꾸지 않습니다.

모델 한도는 10,000자입니다. 다만 Dialogue 문서는 요청당 전체 대사를 2,000자 이하로 권장합니다. 긴 요청은 검증 오류가 나거나 음성이 일찍 끝날 수 있습니다. 도구는 2,000자를 넘으면 경고하고 10,000자를 넘으면 거부합니다. REST API는 서로 다른 목소리를 최대 10개 허용하며 플러그인은 한 요청을 50개 대사로 제한합니다.

요청과 조절 옵션

tts_elevenlabs_generate는 한 목소리를 입력 하나로 바꿉니다. tts_elevenlabs_dialogue는 대사 순서대로 입력을 보냅니다. 둘 다 POST /v1/text-to-dialogue를 호출하며 timestamps:true이면 /with-timestamps를 붙입니다. API 기본 모델은 여전히 v3이므로 v4를 명시합니다.

POST /v1/text-to-dialogue/with-timestamps?output_format=wav_24000
xi-api-key: YOUR_API_KEY
{
  "inputs": [{"text": "[quietly] Hello.", "voice_id": "YOUR_VOICE_ID"}],
  "model_id": "eleven_v4",
  "language_code": "en",
  "settings": {"stability": 0.5, "similarity": 0.75},
  "seed": 42,
  "previous_text": "We arrived.",
  "future_text": "Then we left."
}
도구 인수API 필드와 동작
stability / similaritysettings.stability / similarity. 범위는 0–1이며 공급자 기본값은 0.5 / 0.75입니다. style과 숫자 speed 조절은 지원하지 않습니다.
languageCodelanguage_code. ko 같은 2글자 코드와 ast, yue, ceb, fil을 받습니다.
previousText / nextTextprevious_text / future_text. 각각 100자까지 앞뒤 문맥으로 쓰며 음성으로 읽지 않습니다.
previousRequestIds / nextRequestIdsprevious_request_ids / next_request_ids. 앞뒤 각각 실제 요청 ID 3개까지 받습니다. 앞쪽은 가까운 ID를 마지막에, 뒤쪽은 가까운 ID를 처음에 씁니다. 모델별 지원은 다를 수 있습니다.
pronunciationDictionaryLocatorstts_elevenlabs_dictionary가 반환한 사전·버전 ID를 최대 3쌍 전달합니다.
usePvcAsIvcuse_pvc_as_ivc. 전문 클론의 즉석 클론 버전을 요청하는 선택 옵션입니다. 오류 복구용으로 자동 활성화하지 않습니다.
enableLogging쿼리의 enable_logging. 기본값은 true입니다. false는 Enterprise 전용이며 공급자 기록과 요청 연결을 끕니다. 요청 ID와 함께 쓰면 거부합니다. 로컬 파일은 계속 저장합니다.
seed / applyTextNormalizationseed는 0–4294967295 정수이며 같은 음성을 보장하지 않습니다. 텍스트 정규화는 auto/on/off입니다.

짧은 [오디오 태그]로 말투를 지시합니다. 발음은 슬래시로 감싼 /IPA/를 쓸 수 있습니다. SSML은 거부합니다. 자막 표기와 실제 합성 요청은 따로 보존합니다. 기존 similarityBoost는 similarity의 별칭이며 speed:1은 이전 프로필을 읽으려고 허용할 뿐 API에는 보내지 않습니다.

출력 형식

영상 조립에는 wav_24000을 씁니다. WAV 16·22.05·44.1·48 kHz와 MP3 44.1 kHz / 64·128·192 kbps도 지원합니다. WAV 44.1 kHz는 Pro 이상, MP3 192 kbps는 Creator 이상이 필요합니다. 확장자는 출력 형식과 맞춰야 합니다. output_format은 JSON 본문이 아닌 쿼리로 보냅니다. MP3는 내레이션 조립 전에 변환합니다.

시간 정보와 생성 기록

타임스탬프 요청에서는 audio_base64를 음성으로 저장하고 두 alignment와 voice_segments를 그대로 JSON 파일에 보존합니다. 실제 요청 본문, 출력·로그 옵션, 응답에 있는 요청 ID·사용량·지연 시간도 저장합니다. 정규화된 문자의 위치가 원문과 같다고 가정하지 않습니다. 여러 목소리가 섞인 파일은 대화용 조립 경로가 필요합니다.

목소리와 오류

tts_elevenlabs_voices는 GET /v2/voices를 필터·페이지 옵션과 함께 조회합니다. 실제 ID와 미리듣기 URL을 사용합니다. 키에는 음성 생성 권한이 필요하며 목록 조회는 voices_read, 선택적인 구독 정보 조회는 user_read를 씁니다. 클론 사용 가능 여부는 계정에 따라 다릅니다. v4에서 음색과 언어 간 억양이 달라질 수 있으므로 모델 변경만을 이유로 기존 음성을 재생성하지 않습니다.

사용량

계정의 현재 단가를 적용합니다. 응답의 character-cost는 달러 가격이 아닌 공급자 측정량입니다. 비용 장부에는 이 값을 1,000으로 나눠 기록합니다. 값이 없으면 미확인이며 0으로 계산하지 않습니다. API 재시도에도 비용이 들 수 있습니다. 무료 플랜 출력은 비상업용이며 게시할 때 현재 플랜의 사용 조건을 확인합니다. 이번 업데이트에서는 유료 합성이나 청취 테스트를 하지 않았습니다.

구현과 검증

제작과 대사 수정은 공통 v4 스킬 안내를 따릅니다. 테스트는 공급자 응답을 대체해 본문·쿼리·입력 검사·타임스탬프·생성 기록을 확인합니다. 음질 검증은 아니며 생성 음성은 not_reviewed로 기록합니다.

스트리밍·WebSocket·공급자 audio_effects는 현재 파일 생성 도구에서 지원하지 않습니다. 효과음은 기존 SFX 제작 흐름을 사용합니다.
