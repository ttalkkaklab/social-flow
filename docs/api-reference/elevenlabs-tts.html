1. 모델

Models 페이지의 TTS 가능 모델은 다섯이고, 이 서버는 아래 넷에 폐기 예고된 Turbo 하나를 더해 노출한다(아직 서비스 중이라 기존 프로파일이 깨지지 않게). 요청당 상한은 같은 페이지의 "Character limits" 표 값이다.

model_id성격요청당 상한API 단가비고
eleven_multilingual_v2안정적·자연스러움 — 벤더 convert 기본값이자 이 서버의 기본값10,000자$0.10 / 1Klanguage_code 를 무시한다(본문에서 언어 감지)
eleven_v3표현력 최대, 오디오 태그, dialogue 유일 모델5,000자$0.10 / 1K설계상 느리다(실시간 아님). previous_text/next_text 를 거부한다(400 실측)
eleven_v3_conversationalv3 계열의 실시간 튜닝판5,000자(벤더 표에 없어 v3 값을 적용)$0.05 / 1Kconvert·with-timestamps 는 받는다(실측). dialogue 는 invalid_argument 로 거부
eleven_flash_v2_5가장 빠름(~75ms)40,000자$0.05 / 1Klanguage_code 를 따른다. 정규화를 on 으로 두지 않으면 숫자를 그대로 읽는다
eleven_turbo_v2_5폐기 예고 → flash_v2_5 (스펙에 deprecated: true)40,000자$0.05 / 1K기능은 같고 지연만 크다

노출하지 않은 것: eleven_flash_v2(영어 전용인데 한국어에도 200 을 돌려준다 — 그게 함정이다), 제거된 v1 모델들(라이브 OpenAPI 스펙에 0건). text-to-dialogue 는 eleven_v3 만 받는다 — multilingual_v2 는 model_does_not_support_dialogue, v3 conversational 은 invalid_argument, 둘 다 실측.

기본값이 v3 가 아니라 multilingual_v2 인 이유. 벤더 convert 기본값이 v2 이고, v2 의 with-timestamps 는 실측됐고, 값은 v3 와 같으며, v3 는 실패 모드가 더 있다(Creative 모드 환각, 앞뒤 문맥 미지원). v3 는 필요할 때 라우팅한다 — 오디오 태그와 dialogue. Supertonic 레인이 업스트림 CLI 기본값을 따른 것과 같은 논리다. 같은 요청이 여기서만 다르게 들리면 안 된다.

쿼리 파라미터는 셋뿐이다 — output_format, enable_logging, 폐기된 optimize_streaming_latency. 나머지는 전부 JSON 본문이다. output_format 을 본문에 넣으면 조용히 무시된다(실측 — mp3 가 돌아왔다).

POST /v1/text-to-speech/JBFqnCBsd6RMkjVDRZzb?output_format=wav_24000
xi-api-key: …
{
  "text": "오늘 주제는 환율입니다.",
  "model_id": "eleven_multilingual_v2",
  "voice_settings": { "stability": 0.5, "speed": 1.0 },   // 일부만 보내도 된다
  "seed": 42,                                              // 같은 seed·문장·보이스 → 바이트 단위 동일 파일(실측)
  "previous_text": "…", "next_text": "…",                  // 한 컷만 다시 만들 때 앞뒤 톤 이어 붙이기 — v3 는 불가
  "apply_text_normalization": "on"                         // auto | on | off
}

본문 필드와 범위: voice_settings.stability 0~1(기본 0.5. v3 에선 슬라이더가 아니라 3모드 — 0.0 Creative · 0.5 Natural · 1.0 Robust, 그 외 값은 붙여 맞춘다), similarity_boost 0~1(0.75), style 0~1(0), use_speaker_boost(true), speed 0.7~1.2(1.0); seed 0~4294967295; language_code ISO 639-1 — flash/turbo v2.5 와 v3 는 따르고 multilingual_v2 는 무시; pronunciation_dictionary_locators 최대 3개(아직 노출 안 함). 툴 인자는 같은 이름의 camelCase 다.

3. 출력 포맷과 티어 게이트

비스트리밍 엔드포인트의 열거값은 28종(라이브 API 는 29종 — m4a_aac_44100_128 을 받는데 스펙엔 없다): mp3 8 · pcm 7 · wav 7 · opus 5 · ulaw · alaw. 스트리밍 쌍둥이는 wav_* 를 통째로 뺀다. 이 서버는 제작에 쓰이는 부분집합만 노출한다.

포맷Content-Type(실측)플랜여기서
wav_24000audio/wav — 크기 필드가 맞는 정상 RIFF, 모노 16비트, data 앞에 LIST/INFO 청크 하나전 플랜기본값 — Gemini 레인과 같은 규격, 빌더가 그대로 읽는다
wav_16000 · wav_22050 · wav_48000audio/wav전 플랜노출
wav_44100 · pcm_44100—Pro 이상(그 아래는 403 output_format_not_allowed, 실측)wav_44100 노출(Pro 계정이면 Supertonic 의 44.1kHz 와 맞는다)
mp3_44100_64/128/192audio/mpeg192kbps 는 Creator 이상파이프라인 밖 용도로 노출
pcm_* · opus_* · m4a · ulaw · alawaudio/pcm(컨테이너 없음) · audio/opus(Ogg, "OggS") · audio/mp4—노출 안 함 — 영상 파이프라인에 자리가 없다
왜 WAV 인가, 왜 mp3 는 나레이션 입력이 아닌가. build-reel.sh 는 나레이션 파일의 첫 4바이트를 본다. RIFF 면 컨테이너로 열고, 아니면 raw s16le 24kHz PCM 으로 읽는다. 그래서 mp3 나레이션 파일은 타임라인에서 잡음이 된다. 같은 이유로 툴은 포맷과 어긋나는 확장자의 filename 을 거부한다.

4. 타임스탬프와 대화

with-timestamps

{
  "audio_base64": "UklGR…",                       // 요청한 포맷 그대로의 오디오(wav_* 면 RIFF)
  "alignment":            { "characters": ["안","녕",…], "character_start_times_seconds": […], "character_end_times_seconds": […] },
  "normalized_alignment": { "characters": [" ","a","n","n","y","e","o",…], … },   // 벤더가 정규화한 텍스트 기준
  "voice_segments": [ { "voice_id", "start_time_seconds", "end_time_seconds", "character_start_index", "character_end_index", "dialogue_input_index" } ]  // dialogue 전용
}
normalized_alignment 는 한국어를 로마자로 돌려준다. 한글 14자가 라틴 33자("annyeo…")로 왔으니 원문 인덱스로 못 쓴다. 사이드카 <오디오 이름>.alignment.json 엔 두 객체를 원문 그대로 두고, 서버가 찍는 요약은 전부 alignment 를 읽는다. v3 에선 오디오 태그 글자([whispers] )도 정렬에 들어오는데, 시각은 0 에 가깝다.

text-to-dialogue

본문: inputs: [{ text, voice_id }](둘 다 필수, 줄마다 다른 필드 없음), model_id(기본이자 유일한 값 eleven_v3), settings: { stability } — 스펙의 ModelSettingsResponseModel 은 속성이 이것 하나라 use_speaker_boost 류는 무시된다(엉뚱한 필드를 넣어도 200, 실측). 한도: 요청당 서로 다른 voice_id 최대 10개(capability 페이지의 "화자 수 제한 없음"은 낡은 문장이다 — 10 에 맞춰 짠다), 안정적 생성을 위해 총 2,000자 이하 권장, 하드 상한은 v3 의 5,000자. 실측한 voice_segments 에서 레거시 보이스 ID(Rachel 21m00…)가 현재 ID(eLDc7xhWxG2FElT3kUTj)로 찍혔다 — 레거시 ID 는 아직 먹지만 내부에서 바꿔 쓴다.

5. 보이스·키·오류·한도

보이스는 계정마다 다르다 — GET /v2/voices(쿼리 파라미터 20개 중 이 서버는 page_size ≤ 100, search, category ∈ premade · cloned · generated · professional, include_total_count 를 쓴다)는 voices[] 에 voice_id, name, category, labels {gender, age, accent, language, use_case, descriptive}, description, preview_url, verified_languages[] 를, 바깥에 has_more/next_page_token 을 돌려준다. 레거시 프리메이드 세트(Rachel·George…)는 2026-12-31 에 만료되고, 흔히 도는 프리메이드 ID 21개는 2026-08-23 에 전부 200 이었다. Voice Library 보이스는 무료 플랜 API 에선 못 쓴다. 한국어 품질은 모델이 아니라 보이스가 정한다 — profile.md 에 voice_id 를 고정하고 표시 이름은 절대 쓰지 않는다.

키는 권한 단위다(스펙의 권한 이름 49종): 합성은 text_to_speech, 목록은 voices_read, 플랜 줄은 user_read, GET /v1/models 는 models_read. 제한 키는 401 missing_permissions 에 권한 이름을 찍어 돌려준다 — 실측에 쓴 맥미니 키는 text_to_speech 만 있는 키였다.

오류형태 / status여기서의 처리
현행{detail:{type, code, message, status, request_id, param}} — 문서는 status 를 "레거시"라 하지만 여전히 채워지고 code 보다 세밀하다(401: code=unauthorized, status=invalid_api_key / needs_authorization / missing_permissions)status 로 분기하고 code 로 폴백
구형{detail:{status, message}} — model_not_found 가 아직 이 꼴같은 분기
422FastAPI 배열 {detail:[{loc, msg, type}]}body 접두 없이 한 줄로 합친다
429rate_limit_exceeded · concurrent_limit_exceeded · system_busy; 플랜별 동시 한도 Free 2 · Starter 3 · Creator 5 · Pro 10 · Scale/Business 15(flash 는 두 배); 헤더 current-concurrent-requests/maximum-concurrent-requests3회 시도, 1초·2초 백오프, 그 뒤 "씬을 하나씩 돌려라" 안내

읽을 만한 응답 헤더: character-cost(벤더의 계량치 — 실측한 모든 호출에서 원문 글자 수보다 적었다: 한국어 18 → 10, 영어 28 → 15), request-id, tts-latency-ms. 서버는 셋 다 보고한다.

6. 요금과 라이선스

API 사용은 1,000자당 달러로 매기고 어느 플랜이든 같다(pricing/api, 2026-08-23 열람): multilingual_v2·eleven_v3 $0.10, flash/turbo·v3 conversational $0.05. 플랜마다 이 계량기 기준 월 글자 할당이 들어 있다(Free 10,000 · Starter $6 → 60,000 · Creator $22 → 220,000 · Pro $99 → 990,000 — $0.10 모델 기준이고 $0.05 모델은 두 배). 메인 요금 페이지의 "크레딧" 표는 웹 UI 계량기라 API 와 다르다. 원장엔 키 tts.elevenlabs(v2·v3) 또는 tts.elevenlabs-flash(flash·v3 conversational), 수량은 character-cost ÷ 1000 으로 적는다.

무료 플랜엔 상업 라이선스가 없고("cannot be used for any commercial purpose") 출처 표기 — 제목에 "elevenlabs.io" 또는 "11.ai" — 를 요구한다. 유료 플랜은 전부 상업 라이선스를 포함하니 수익 채널은 Starter($6)가 바닥이다. Voice Library 보이스·IVC·192kbps 는 Starter/Creator 부터, 44.1kHz PCM/WAV 는 Pro 부터다.
