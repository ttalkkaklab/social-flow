3. 4가지 생성 모드

툴추가 입력결과 길이고유 제약
veo_text2video없음4/6/8초—
veo_img2videoimage (+ lastFrame)4/6/8초이미지는 로컬 파일을 base64 인라인으로 읽는다
veo_extensionvideo+7초입력은 Veo 생성물 · 720p · 141초 이하. 최대 20회 연장. 마지막 1초에 음성이 없으면 음성은 이어지지 않는다
veo_referencereferenceImages 1~3장8초 고정여러 각도의 선명한 이미지일수록 일관성이 올라간다
 
// 연장 — 공식 샘플과 동일하게 durationSeconds·aspectRatio 를 넘기지 않는다
const operation = await genai.models.generateVideos({
  model: 'veo-3.1-generate-preview',
  prompt: '카메라가 천천히 뒤로 빠지며 전경을 보여준다',
  video: { videoBytes: base64, mimeType: 'video/mp4' },
  config: { numberOfVideos: 1, resolution: '720p' },
});
veo_extension의 응답 Added Duration은 추가된 길이(+7초)지 전체 길이가 아니다. 20회까지 누적하면 원본 8초 + 140초가 된다.

4. 비동기 폴링과 다운로드

생성은 즉시 완료되지 않는다. SDK가 반환한 operation.name을 REST로 폴링한다.

GET https://generativelanguage.googleapis.com/v1beta/{operation.name}
x-goog-api-key: {API_KEY}
키는 ?key= 쿼리가 아니라 x-goog-api-key 헤더로 보낸다 — URL은 로그·에러 메시지에 에코될 수 있어 유출면이 되지만 헤더는 그 경로가 없다. 실측(2026-07-29): 헤더 인증으로 unregistered-caller 게이트를 통과함을 확인.
응답 필드의미
done완료 여부
error.message생성 실패 사유
response.generateVideoResponse.generatedSamples[].video.uri결과 영상 URI (현행 형식)
response.generatedVideos[].video.uri구 형식 — 호환을 위해 함께 확인
response.generateVideoResponse.raiMediaFilteredReasons[]책임 AI 필터에 걸린 사유. 비어 있지 않으면 결과가 없다

영상 URI 다운로드도 같은 헤더 인증을 쓴다. 서버는 10초 간격 · 최대 60회(=10분) 폴링하고, 초과 시 Video generation timed out (10 minutes)로 실패한다.

RAI 필터는 done: true + 빈 결과로 온다. raiMediaFilteredReasons를 먼저 보지 않으면 "영상이 없다"는 모호한 에러가 되어 모델이 같은 프롬프트로 재시도한다 — 그 재시도는 반드시 다시 걸리고 대기 시간만 소모된다.

모든 결과물에는 눈에 보이지 않는 SynthID 워터마크가 들어간다.

운영에 걸리는 공식 제한 (2026-08-15 재확인)

제한내용
결과 보관2일 뒤 서버에서 삭제된다. 이 서버는 생성 즉시 로컬 저장이라 무해하지만, 며칠 뒤 연장하려면 로컬 파일이 있어야 한다
차단 시 과금안전 필터·오디오 처리로 생성이 막히면 요금이 청구되지 않는다
지연최소 11초 · 최대 6분(피크). 이 서버의 폴링 상한 10분은 여유가 있다
언어영어만 완전 지원. 다른 언어는 평가되지 않아 결과가 달라질 수 있다
다중 영상 참조영상 여러 개를 참조·추론하는 기능이 없다. 시도하면 품질이 떨어진다
지역EU·영국·스위스·MENA 계정은 personGeneration 이 allow_adult 로 좁혀진다

5. 프롬프트 규칙

  • 오디오는 네이티브 생성이다. 대사는 큰따옴표로 감싸고, 효과음("engine roaring")과 환경음을 프롬프트에 명시적으로 적는다.
  • 영어 프롬프트가 더 안정적이다.
  • 쇼트폼은 aspectRatio: '9:16'이 기본 선택지다.
  • 비용 레버: 초안·테스트는 lite(1/8), 중간 품질은 fast(1/4), 최종 컷만 기본 모델.
