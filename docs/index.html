스킬 18종 — 무엇을 언제 부르나

채널 하나를 열어 콘텐츠를 올리기까지의 순서다. 각 단계는 앞 단계의 산출물을 검사해서, 스토리보드가 미승인이면 produce 가, 제작이 안 끝났으면 publish 가 멈추고 이전 단계를 안내한다. 인자 형태와 전체 계약의 정본은 README.md 다.

API 레퍼런스

내부 MCP 서버(server/src)가 실제로 호출하는 모든 외부 API의 공식 계약을 정리하고, 이 저장소의 구현이 그 계약을 어떻게 지키는지(또는 의도적으로 좁히는지) 함께 적었다.

사용 가이드

/social-flow:ingest — 화면 녹화와 음성 타임라인으로 소재를 수집하는 흐름.

스크린캐스트 제작 →

대본 → 촬영 → 정합 → 편집으로 이어지는 스크린캐스트 파이프라인.

AI로 쇼트폼 영상 만들기 →

Veo 와 Seedance 를 가르는 축은 길이가 아니라 그 구간의 소리다. 프롬프트 공식 규칙, 자막을 영상에 태울지, 그리고 아직 답이 없는 영역 셋.

스레드 성장 베스트 프랙티스 →

/social-flow:grow-threads — 게시물 단위 심사·랭킹 5신호·반말 문체·스하리 문화로 스레드를 키우는 법.

유튜브 쇼츠 성장 베스트 프랙티스 →

AI로 만들 때 수익화가 막히는 경계선, 2027년 YPP 개편이 만든 마감일, 공식 문서가 직접 부정하는 통념.

인스타그램 릴스 성장 베스트 프랙티스 →

계정 단위 추천 자격과 게시물 단위 오디션이라는 두 관문, 랭킹이 실제로 예측하는 항목, 검증에서 죽은 통념 9개.

제휴 영상 규칙 →

쇼핑 커넥트 상품을 유튜브 영상으로 홍보할 때 지나야 할 관문 다섯. 안 써본 상품의 화법, AI 캐릭터 표시, 그리고 상품 사진을 AI에 물릴 수 없는 이유.

서비스 기획

공공데이터와 쇼트폼 소재에서 출발해 실제 제품으로 검증할 서비스 아이디어를 정리한다.

동네 변화 레이더 →

주소를 구독하면 주변 건축·상가·공공공사의 공식 변화를 모아 알려주는 생활권 변화 알림 서비스.

관련 점포 레이더 →

가게를 열기 전에 같은 상권, 같은 업종의 개업·폐업을 보고 자리를 고르는 서비스. 액터·페르소나·인터뷰 통증·채택 아이디어.
