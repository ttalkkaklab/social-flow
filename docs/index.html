API 레퍼런스

내부 MCP 서버(server/src)가 실제로 호출하는 모든 외부 API의 공식 계약을 정리하고, 이 저장소의 구현이 그 계약을 어떻게 지키는지(또는 의도적으로 좁히는지) 함께 적었다.

API 레퍼런스 허브 →

11개 API 인벤토리, 자격증명 매트릭스, 툴 ↔ API 매핑표.

툴 품질 감사 리포트 →

31개 툴을 공식 문서 계약 + MCP 스펙 + 툴 작성 베스트 프랙티스로 채점한 결과와 수정 내역.

사용 가이드

화면 녹화로 쇼트폼 만들기 →

/social-flow:ingest — 화면 녹화와 음성 타임라인으로 소재를 수집하는 흐름.

스크린캐스트 제작 →

대본 → 촬영 → 정합 → 편집으로 이어지는 스크린캐스트 파이프라인.

AI로 쇼트폼 영상 만들기 →

Veo 8초 상한이 정하는 파이프라인 구조, 프롬프트 공식 규칙, 자막을 영상에 태울지, 그리고 답을 못 낸 영역 넷.

스레드 성장 베스트 프랙티스 →

/social-flow:grow-threads — 게시물 단위 심사·랭킹 5신호·반말 문체·스하리 문화로 스레드를 키우는 법.

유튜브 쇼츠 성장 베스트 프랙티스 →

AI로 만들 때 수익화가 막히는 경계선, 2027년 YPP 개편이 만든 마감일, 공식 문서가 직접 부정하는 통념.

인스타그램 릴스 성장 베스트 프랙티스 →

계정 단위 추천 자격과 게시물 단위 오디션이라는 두 관문, 랭킹이 실제로 예측하는 항목, 검증에서 죽은 통념 9개.
