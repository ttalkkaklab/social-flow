# 관객용 심리 효과음 설계 검토

검토 대상은 [설계 문서](blueprint.md)다. 첫 독립 검토에서는 기존 보드와 사운드 컴파일러도 읽었다. 같은 샷에 중복된 효과 ID가 있을 때의 처리, 편집 시각을 다시 맞출 조건, 컷을 넘는 음의 데이터 형식, 납품 배속을 반영한 시간 계산을 보강했다.

두 번째 독립 검토는 수정된 문서를 읽고 90/100점, P0·P1 각 0건으로 평가했다. 이후 지적에 따라 채널 카탈로그 경로와 리졸버, 효과음을 켜고 끄는 구간 렌더 옵션의 제안 인수를 8절에 명시했다. 두 번째 점수는 이 마지막 문구를 추가하기 전 판정이다.

작성 중 현재 배포 번들의 준비 함수에도 같은 추상음 지시를 넣어 비교했다. `auto`는 `native`를 선택해 설명을 영상 프롬프트에 더했고 `post`는 설명을 보내지 않았다. 두 경로 모두 `generated:false`를 반환했다. 설계 예시의 JSON, 조사 사례 번호, 근거 파일 경로와 배속 계산도 확인했다. 새 기능을 구현한 뒤 들어야 할 최종 믹스와 회귀 테스트는 설계 9절에 적었다.
