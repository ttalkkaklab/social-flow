# 영상 모델 라우팅 개선 결과

2026-10-18 기준으로 세 차례 독립 평가를 거쳐 100점을 받았다. 요청 기준은 95점이며 최종 평가에서 차단 결함을 찾지 못했다.

| 평가 | 점수 | 차단 결함 | 수정 내용 |
|---|---:|---:|---|
| 1차 | 85 | 3 | ASTRA 기존 표기, 부분 재생성 해상도, 제작 검사와 실행기의 선택 우선순위 |
| 2차 | 80 | 2 | ASTRA 내부 재시도와 요청 기록, 다른 생성 도구의 비용 기록 누락 |
| 3차 | 100 | 0 | 추가 수정 지시 없음 |

선택 함수, 모델 레지스트리, 실행 전 검증, 비용 예약, 공급자 어댑터를 분리했다. 제작 검사와 음성 계획도 같은 선택·기능 계약을 읽는다.

`video_catalog`로 설치된 어댑터를 조회하고 `video_plan`으로 요청을 저장한 뒤 `video_execute`로 실행한다. `video_status`는 저장된 상태와 공급자 요청 ID를 읽는다. 기존 영상 도구는 `videoContext`를 받으면 같은 경로를 사용한다.

동시 요청은 파일 잠금 안에서 비용과 실행 자리를 예약한다. 완료된 요청은 결과를 재사용한다. 응답이 끊긴 요청이나 예상 밖의 추가 제출은 예약을 유지하며 다시 제출하지 않는다. 호스트 도구와 독립 실행의 적용 범위는 문서에 따로 적었다.

- 전체 검사: 2,266개 통과, 실패·건너뛰기 0개.
- 독립 검토자의 라우팅 검사: 25개 통과.
- 스킬 검사: 21개 스킬, 16개 규칙 통과.
- 실제 유료 API 호출은 하지 않았다. 공급자 가용성, 생성 품질, 실제 청구액은 검증하지 않았다.
