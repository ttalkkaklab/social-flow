Each implementation revision is built, installed with backups, and exercised from a fresh installed MCP process. An independent read-only verifier receives artifacts and this rubric, not optimizer rationale. Keep failures and correction directives. No score shopping on unchanged media; change the defective input/output before re-review. Record media hashes, input arguments, model and timestamped observations. Sampled frames supplement a Gemini full-media review; the parent never claims direct listening from a receipt.
