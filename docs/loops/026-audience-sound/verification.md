# 관객용 효과음 검증

평가자는 제작자의 채점과 별개로 코드와 검증 기록을 읽었다. 합격 기준은 95점 이상, 치명적 결함 0건이다. [평가 항목](loop.md)

| 회차 | 점수 | 치명적 결함 | 다음 수정 |
|---|---:|---:|---|
| 1 | 91 | 0 | 다음 컷의 전환과 실제 음원 바이트가 바뀌면 위치를 다시 확인한다. 삽입 영상 앞에서 드론을 20ms 동안 줄이고 실제 삽입·배속을 반영한 납품 시각을 기록한다. |
| 2 | 91 | 0 | 트림 계산 결과를 48kHz 샘플에 맞춘다. 편집한 영상에 삽입 컷을 실제로 합치고 배속을 바꿔 소리를 검사한다. 불완전한 음원 파일의 중복 발주 검사도 보강한다. |
| 3 | **96** | **0** | 독립 평가자가 보드·믹서·음원 재사용 테스트를 재실행하고 배포용 120개 사례를 직접 세었다. |

최종 배점은 보드 편집 24/25, 합성 24/25, A/B 19/20, 사례 자료 15/15, 호환·재시도 14/15다. 전체 서버 테스트 1,927개와 스킬 검사를 통과했다. 테스트 중 기존 커버 렌더러의 Chrome 프로세스가 한 번 종료되어 해당 검사와 전체 검사를 다시 실행했다.

## 무엇을 재현했나

- 말실수의 민망함을 다룬 063번을 찾아 보드에 계획했다. 보드 읽기, 배치, 같은 요청 재시도, 원본 교체, 재배치, 효과 하나만 삭제하는 과정을 확인했다.
- 원본 0.80초부터 트림한 카드에서 원본 2.20초의 반응에 드론을 맞췄다. 본편 1.40초에 시작하고 다음 카드 0.50초에 끝났다. 같은 구간에 놓인 다른 합성음과 원음은 이어졌다.
- 두 비교 영상의 프레임을 해시로 대조하고 효과음 구간 전후의 PCM 샘플을 비교했다. 두 버전은 동일한 기본 믹스와 프리뷰 게인을 쓴다. 납품본에는 통상적인 최종 음량 처리를 적용한다.
- 같은 보드에 1초짜리 삽입 영상을 넣어 다시 조립했다. 원래 드론은 삽입 직전에 사라졌고 삽입 영상 자체의 소리가 들리는 구간에서는 해당 드론의 주파수 성분이 사라졌다. 다음 반응점은 실측한 삽입 길이와 1.25배 재생 속도를 반영한 위치에서 확인했다.
- 외부 생성기를 모의 응답으로 바꿔 같은 음원을 동시에 두 번 주문했을 때의 호출 수를 셌다. 유료 제출은 한 번이고, 같은 음원의 재사용·타임아웃 뒤 재시도·불완전한 음원 파일에서는 추가 호출이 없었다.

기술 검증에는 합성 톤을 썼다. 실제 작품에서 관객이 느끼는 감정과 대사 가청성은 완성 구간을 들어야 판단할 수 있다.
