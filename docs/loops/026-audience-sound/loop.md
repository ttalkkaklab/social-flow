# 관객용 효과음 구현 평가

독립 평가자가 편집과 합성을 재현해 100점 만점으로 채점한다. 통과 기준은 95점 이상, 치명적 결함 0건, 서버 계약 검사와 스킬 검사 통과다.

| 항목 | 배점 |
|---|---:|
| 보드에서 계획·배치·재편집하고 오래된 위치를 찾는다 | 25 |
| 실제 편집 시간에 한 번만 합성하고 대상 소리만 끝낸다 | 25 |
| 같은 구간과 기본 믹스로 청취용 A/B를 만든다 | 20 |
| 설치본에서 12개 분류와 120개 상황을 찾아 제작에 쓴다 | 15 |
| 기존 보드, 소리 소유권, 재시도와 검사 증거를 보존한다 | 15 |

자료 손실, 중복 합성, 영상 원음 훼손, 생성기에 관객용 효과 전달은 치명적 결함이다.

## 평가 결과

독립 평가 점수는 91점, 91점, 96점이었다. 최종 평가에서 치명적 결함은 0건이었다. [회차별 수정과 검증 기록](verification.md)
