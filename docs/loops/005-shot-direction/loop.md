no critical defects, `cd server && npm run check` and skill-lint both exit zero.

of inspected/generated media, credential exposure, or replacement of newer installed
behavior with an older repository baseline.

## Frozen artifact rubric

Score the delivered storyboard and actual video separately from code. Target: >=95
and no critical defects. Each criterion has five equally weighted evidence items;
award each only after inspection, never from prompts or metadata alone.

| Criterion | Weight | Evidence items |
| --- | --- | --- |
| Story and character readability | 25 | opening situation; clear want; obstacle; motivated response; visible payoff |
| Visual continuity | 25 | character identity; prop identity; screen direction; location coherence; readable joins |
| Action and camera | 25 | readable action; purposeful framing; intended move; readable endpoint; adequate reaction time |
| Delivery quality | 25 | complete playback; correct dimensions/timing; no unintended text; no freeze/loop padding; no distracting generation defects |

Critical: missing clip or story beat, visibly broken main character/action, illegible
payoff, fabricated review evidence, or delivered footage not generated by LTX.
The reviewer must inspect temporal evidence. Stills alone cannot earn motion or
complete-playback points. Unavailable review capability stays unreviewed and cannot
be awarded points. Record each iteration and named fixes without changing criteria.
