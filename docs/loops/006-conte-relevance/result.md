The original board attached only the first editorial cut of each narration block.
Its43 representative images reused34 files, while the underlying plan contained66
cuts. A generic three-box drawing helper flattened distinct narrative functions,
and chapter scores copied into shots concealed local defects.

The plugin now displays every planned cut with its length and source range, exposes
missing/short media, and provides a read-only inventory for coverage, exact duplicate
bytes and inherited chapter scores. Semantic fit remains native visual review, not
an automatic score. Authoring/reviewer guidance covers factual boundaries, meaningful
graphic relations, actual recurring-object/person continuity and information-free
inserts. Tests cover rendering, source-range playback and inventory edge cases.

reloaded its entrypoints and rebuilt the storyboard. Both Codex0.115.4 and Claude0.115.3
