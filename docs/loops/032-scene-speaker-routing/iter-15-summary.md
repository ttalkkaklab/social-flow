# Restore the actual speech operation from completed scene requests

Per-shot scene renders archive the submitted body and ordered upload records. New generation receipts bind that archive's digest. Attachment and assembly verify the model, shot intervals, physical dialogue, and whether the track supplied the performance or was mixed externally. A supplied per-shot performance is compared with the same lossless staged WAV used by the renderer.

For a full-scene driver, the current recordings are checked at the recorded frame offsets. A card bound to a shared scene output selects its own source interval. The regression cases cover a changed recording, a source used for outside narration, native speech, a legitimate soundtrack remux, and the original silent-output conditioning route.
