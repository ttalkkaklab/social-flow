# Bind recorded voice and image references to their original owners

Scene generation and assembly use the same character voice resolver. Each physical dialogue row is matched to the staged sample for its speaker, including repeated turns in one frame and gateway uploads with opaque identifiers. Native scene reattachment also verifies the authored character images and frame pins. Explicit generated voices on supporting models still follow their registered route.

A managed full-track request retains its approved line recordings and timing alongside the submitted master. The provider body stays unchanged. After completion the saved request digest lets assembly retain the original stereo mix while checking every current input. The regression fixtures include both a changed native voice and a legitimate mixed master.
