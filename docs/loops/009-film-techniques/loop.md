# 확정 평가 기준

사용자가 “허용 할테니 진행해.”로 평가 기준과 추가 음성 비용 최대 US$1을 승인했다. 원래 요청대로 두 대상이 각각 95점 이상이 될 때까지 개선한다.

| 대상 | 항목 | 배점 |
|---|---|---:|
| 플러그인 | 네 요소와 기법 선택·저장·표시·프롬프트 전달 | 40 |
| 플러그인 | 전체 빌드·계약 검사 | 25 |
| 플러그인 | 기존 보드·설치본 회귀 검사 | 15 |
| 플러그인 | 저장소 규칙과 문체 | 10 |
| 플러그인 | 요청 범위와 변경 안전성 | 10 |
| 실제 영상 | 인물 동일성 | 20 |
| 실제 영상 | 선택한 기법·프레이밍 일치 | 20 |
| 실제 영상 | 행동과 컷 연결 | 20 |
| 실제 영상 | 대사·타이밍 | 20 |
| 실제 영상 | 편집과 화면 완성도 | 20 |

각 대상이 95점 이상이어야 한다. 실제 영상을 확인하지 않은 항목은 점수를 줄 수 없다. 치명적 결함은 입력 훼손, 서버 시작 실패, 핵심 행동 누락, 인물 식별 실패, 대사 절단이나 다른 대사 출력이다. 무대사 컷만으로 대사 항목을 평가하지 않는다. 파일 해시와 구간을 근거로 독립 검토자가 평가한다.

첫 전체 검사: 2,215개 중 2,210개 통과. 카탈로그 파일이 없는 번들 시작 2건, HTML 내보내기 수 2건, HTML 테스트의 새 스크립트 의존성 1건을 수정했다. 수정 후 관련 30개 검사는 통과했다. 이 기록은 적대적 품질 평가 점수가 아니다.
