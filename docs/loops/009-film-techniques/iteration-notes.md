# 기법 적용 보완 기록

## 플러그인

캐릭터 참조 4개, 카메라 27개, 프레임 9개, 시간 목적 5개를 공통 사전으로 만들었다. 개별 아이콘과 사용 상황, 안정적인 ID를 스토리보드 HTML·JSON·읽기 도구가 공유한다. 각 컷은 shot.techniques에 ID와 이유를 저장한다. MS는 허리 위, MFS는 허벅지 중간으로 통일했다.

실제 이미지·영상 프롬프트 경로에 시점, 시작 구도, 카메라 기법을 전달한다. 정지 이미지에는 시간에 따른 초점 이동을 요구하지 않고 초점 대상의 깊이를 배치한다. 고정 카메라나 돌리 줌의 횟수 대신 컷의 정보와 행동을 검토한다. 잘못된 ID와 null 배열은 진단으로 보고하고 도구가 중단되지 않게 했다.

전체 검사 2,218개와 설치본 회귀 검사를 통과했고 독립 기술 재검토에서도 앞서 지적한 네 결함이 해소됐음을 확인했다. Codex와 Claude의 로컬 캐시에 세 번 설치한 내역은 원본 백업·파일 해시와 함께 보관 중이다. 이 결과는 코드 검증이며 영상 품질 점수는 별도로 평가한다.

## 멜레온

원본 scenes.js를 프로젝트의 .work/film-techniques-v1/scenes.before.js에 백업했다. 28컷에 선택 이유 170개를 저장했다. 실제로 확인한 시작 이미지에 맞춰 2번 장면의 MFS/MS와 다나카 컷의 MS를 정정했다. 두 대화 컷의 시선 연결 번호도 현재 편집 순서에 맞췄다.

s0205 후보 1은 4.375초로 생성했지만 3.708초와 4.333초 프레임에서 퇴장한 남성이 다시 보였다. 배치와 구도도 바뀌어 제외했다. 유지 조건을 종료 상태 앞에 적고 연속된 한 컷임을 명시했으며 해당 컷의 이동 주체와 제자리 유지 조건을 구체화했다.

후보 2에서는 샘플 프레임 기준으로 재등장이 사라졌다. 원본 후보를 보존하고 후보 2를 아직 검토하지 않은 영상으로 연결했다. 대사 경로는 기존 다나카 음성을 재사용해 5.708초 영상을 생성했고 원래 음성을 로컬에서 결합했다. 새 음성 생성 비용은 없다. 요청한 704×1280·24fps 출력과 길이를 ffprobe로 확인했으며 발음·입 모양 동기화 점수는 아직 없다.

전체 재생·청취와 연결 평가를 완료하지 않아 종합 점수는 없다. 평가 기준과 추가 음성 비용 상한에 대한 질문도 답변을 기다린다. 95점을 선언하거나 dev 머지·워크트리 정리를 먼저 실행하지 않는다.
