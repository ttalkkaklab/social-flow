# 025 — 클리셰 선택 단계 (cliche-use)

날짜: 2026-11-18 · 분류: Preset A(기능 구현) 조정 · 최대 반복 5 · 통과: 점수 ≥ 95 AND P0 0 AND 객관 게이트 통과(사용자 지시로 기준을 90에서 95로 올림)

## 목표 (원문)

> 이 플러그인에서 시놉시스나 스토리보드 작성 시, llm 이 적절하게 클리쉐를 조사한 결과에 따라서 상황에 맞게 추가하게 하려면 어떻게 하는게 좋을지 설계해서 알려줘.
> 드라마 로멘스 코미디 적용을 기본으로 하자. 그 외에는 필요시 사용자에게 추천하고 사용자 선택 시 적용. 표시하는걸로 해줘. 그렇게 플러그인을 개선하고 적대적으로 평가해서 95점 이상될때까지 개선해줘.

루프에 넘긴 목표 문장: social-flow 플러그인의 시놉시스·스토리보드 작성에 클리셰 선택 단계를 넣는다(드라마·로맨스·코미디 기본 적용, 그 외는 추천 후 사용자 선택 시 적용, 검토 화면에 표시). 적대적 평가 95점 이상까지 개선

조사: `docs/research/2026-11-18-kdrama-cliches/` (보고서 한 편, research_notes 아홉 편, index.html)

## 작성자 결정 (사용자가 위임)

1. 영상 유형 목록(`skills/_shared/video-types.json`)에는 로맨스가 없다. 그래서 `drama`·`comedy` 유형은 기본 적용이고, `custom` 유형은 설명에 로맨스·드라마·코미디가 있고 다큐가 없을 때 기본 적용이다. 새 유형은 추가하지 않는다.
2. "기본 적용"은 빠지지 않는 작성 단계와 매 보드 쓰기의 보고로 구현한다. 점수나 관문은 만들지 않는다(CLAUDE.md 2026-10-16 Guided automation, 2026-10-31 Checks removed for speed).
3. 그 외 유형에서 "사용자 선택 시 적용"은 기록 구조로 지킨다. 추천은 `offered`로만 기록되고, 적용 기록에는 `basis:"user"`가 있어야 한다. 이 표시 없이 적용을 기록하면 도구가 받지 않는다. 무인 실행은 사용자가 없으므로 적용하지 않는다.
4. 채널에 계속 적용할 선택(항상 쓴다, 쓰지 않는다)은 `.social-flow/models.json`의 `production.clicheUse`에 저장한다.
5. 기존 보드는 재촉하지 않는다. 이 기능이 들어간 뒤 만든 에피소드 보드만 결정 전까지 "미정"으로 보고한다.

## 기능 여섯 가지 (기준 1이 세는 단위)

- **K1 목록과 선택** — 조사한 클리셰가 태그(층, 필요, 장르, 주의) 붙은 목록으로 플러그인 안에 있고, 선택 스크립트가 이야기의 필요로 후보 몇 개만 돌려준다. 목록 전체를 읽히지 않는다.
- **K2 기본 적용** — 드라마·로맨스·코미디 에피소드는 캐스팅, 시놉시스, 장면 작성에서 클리셰 단계를 기본으로 거친다. 새 에피소드 보드는 결정(사용 또는 없음)을 기록하기 전까지 매 보드 쓰기에 "미정"으로 보고된다.
- **K3 추천 후 선택** — 그 외 유형은 추천만 기록·표시되고, 사용자가 고른 것만 적용으로 기록된다. 사용자 선택 표시 없는 적용 기록은 받지 않는다. 채널에 저장한 선택이 있으면 그것을 따른다.
- **K4 표시** — 공용 스토리보드 검토 화면이 결정 상태(미정, 사용, 없음, 추천), 장면별 클리셰, 옮긴 점(반 보), 적용 근거(기본, 사용자 선택)를 한국어와 영어 UI로 보여 준다.
- **K5 안전장치** — 강압적 스킨십과 폭력 수위 항목은 선택에서 기본 제외하고 기록하면 경고한다. 실제 작품의 대사는 문형만 쓰라고 알린다. 제작 관행 항목은 후보에서 뺀다. 같은 채널의 앞선 에피소드와 겹치면 보고한다. 어느 것도 점수나 관문이 아니다(거부는 도구가 쓸 수 없는 입력과 사용자 선택 표시 누락뿐이다).
- **K6 문서 일치** — CLAUDE.md 지침 섹션, README(도구 표, 도구 개수, 구조), storyboard SKILL.md(지침 문단, 단계 연결, allowed-tools 쌍), 공유 문서(video-types, production-workflow, autoproduce, model-settings, scenes-schema)가 구현과 맞다.
