# Acceptance examples added November 23

A shot has one optional composition reference. Submit it only through a compatible reference input. The opening and ending anchors belong to the scene. When the selected operation cannot accept the guide, the plan explains its omission.

Scene direction on the storyboard uses an icon for each available attribute. Hover, keyboard focus and touch expose the existing localized label and complete value. Shot direction keeps its existing display.

These examples refine the functional coverage and regression criteria in the original rubric.
