# Opening hook authoring and three-second review

The requested implementation must score at least 95 out of 100 in an adversarial review, with zero critical defects. Freeze the following rubric before the first scored evaluation. Test the installed MCP surface, the authoring workflow and the delivered local review page. Use fixture ballots and measurements for reproducible decisions. They make no prediction about real audience behavior.

| Criterion | Points | Full-credit evidence |
|---|---:|---|
| Hook selection and inheritance | 20 | All 18 catalog choices, validated synopsis alternatives, selected-to-board inheritance and explicit direct-board selection work at the public boundary. Updates, missing IDs, raw writes, deliberate reselection and existing boards preserve the contract. |
| Three-second evidence and decisions | 20 | Independent blind inputs exclude private intent and later cues. Clip to the actual window or flag missing evidence. Three distinct evidenced reads, median risk, equality, and compatible same-version observations produce the correct result and units. |
| Revision budget and recovery | 20 | Only above-ceiling openings trigger automatic editing. Five total rounds are shared across candidates and stages. Check stale evidence, retry, simultaneous writes, partial failure, type stability, returning the best eligible opening and honest exhaustion. |
| Objective verification | 25 | Award all 25 only if the complete server build and tests, repository skill lint and distribution consistency pass. A failing required command precludes acceptance. |
| Usability and regressions | 15 | The hosted authoring instructions can be followed for synopsis-only, direct board and unattended work. The offline overview shows current evidence, visible failures and units. Older work remains readable. Inspect and test the actual public entry points. |

A critical defect includes silently writing a new authored board without a valid hook, fabricating a pass without evidence, exceeding the five edits in one run, mistaking estimated risk points for actual audience loss, or a failed required check. Record reproducers and deductions against these fixed criteria. Prior scores have no weight in the next independent review.
