# Independent behavior trial

The `behavior_trial` agent received the updated storyboard skill, production image
guidance and seven raw cases. It did not receive the patch rationale, expected answers
or this rubric. No network, generation, spending or episode edits were allowed.
Only case 6 supplied actual pixels; no video playback was inspected.

| Case | Observed behavior |
|---|---|
| Examination corruption, recollection only, empty courtyard | Attributed the recollection in proposed voice; assigned contextual/reaction role and expressly avoided invented bribery, officials or documents. It did not claim the image depicted corruption. |
| Fictional letter transfer | Opening kept letter with sender and receiver empty-handed; action included reach, grip, release; end assigned custody to receiver. Proposed controlled character animation, with no provider assumed. |
| Good heart versus good face, unauthenticated book | Used established mirror/book as bounded reaction; did not invent a readable passage or literal image of moral virtue. |
| Later public service, opening-only scope | Initial result replaced the narrated bridge with “For now, our story returns to his study.” This was an editorial regression: convenient visuals must not silently change requested meaning. |
| Silent fictional plant watering | Preserved empty narration, pre-pour opening and visible pouring action; kept leaves wilted afterward instead of claiming instant recovery. |
| Actual Kim Gu scene-4 image and corruption narration | Opened the image. Reported one person, rolled paper and empty courtyard; contextual fit only, paper contents/identity/history unverified. Distinguished photographic appearance from preset compliance and still from performed motion. |
| Reading line changed to disputed account; no regeneration authorization | Reassessed content purpose and stale prompt; did not fabricate disputants or regenerate. Missing pixels and factual basis remained unverified. |

Correction after the initial trial: grounding guidance now explicitly preserves approved
narration and permits a bounded forward reference outside the opening's visible timeframe.
Case 4 was rerun with the sentence explicitly approved. The agent retained it exactly,
described the doorway as a contextual bridge rather than evidence of later service, and
kept later-life scenes outside scope. Its proposed closing study view was conditional on
asset availability, not a claim that any edit or new media existed.

This exercise validates authoring decisions on bounded cases, not generated image quality.
The shared source assembler regressions separately exercise actual prompt construction.
