# Shot boundary integrity — frozen rubric

Target: improve the plugin, then adversarially evaluate and improve until at least 95/100.
User later added: install on this Mac, improve insight episode 2 with the updated plugin,
and regenerate affected images with the saved model.

| Criterion | Points | Evidence |
| --- | ---: | --- |
| Diagnostic accuracy | 30 | No semantic deletion claims from character overlap; no jump-cut verdict from size/angle alone; distinguish generated plans from still cards. |
| Edit integrity | 30 | Preserve intentional edits and assets; expose speech/action/reference changes; track changed opening/performance/prompt inputs; do not certify pixels from hashes. |
| Authoring and runtime | 20 | Consistent shot-boundary guidance, uninterrupted scene evidence, explicit timing limits, loaded-build identification and fresh installed connection. |
| Regression and verification | 20 | Targeted regressions in existing module tests, bundled outputs, npm run check and skill-lint pass; adversarial findings resolved. |

Pass: at least 95, no P0 defects, required checks pass. Scores are reviewer judgments,
not a guarantee that every future storyboard is good. No generation/publication permission
is inferred from a score. Keep this rubric unchanged between iterations.

P0: silent data loss, unwanted paid/public action, credential disclosure, or required check failure.
Reviewers receive artifacts and this rubric without the author's self-assessment or previous scores.
