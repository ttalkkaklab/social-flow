# Motion language implementation and installed adversarial trials

User target: improve the plugin, install on this Mac, generate diverse motion graphics through the installed plugin, verify storyboard type selection and refined/readable output, repeat installation and independent adversarial evaluation when score <=95.

The user's explicit until-target instruction takes precedence over the generic loop skill's iteration cap. No paid generation or publication is needed. The baseline working tree was clean at 44748d5.

Frozen rubric (each sample is scored independently; no averaging away failures):
- Type selection 25: fit to intent (10), reason and alternatives (5), evidence honesty (5), persisted and visible storyboard choice (5).
- Visual design 30: intentional composition (10), visual hierarchy (10), coherent subject-appropriate styling without generic garnish (10).
- Legibility 20: correct local font and readable glyphs (5), clear type/units (5), no collision/clipping (5), readable final hold (5).
- Meaningful motion 15: causal/relational action (5), clear order and focus (5), temporal evidence of transitions and rests (5).
- Installed reproducibility 10: installed source provenance (5), executable replayable output and correct dimensions/timing (5).

Each dimension earns points only with cited evidence. Critical defects: wrong data, misleading evidence, broken installed execution, unreadable/clipped primary content. Exit requires project check + skill lint pass, every reviewed sample >95 and zero critical defects. Scores are subjective judgments, not a guarantee of aesthetic quality. Unobserved playback/audio must be stated. Reviewers receive files and the rubric without the optimizer's self-assessment.
