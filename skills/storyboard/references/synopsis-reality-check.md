# Reality check after writing the synopsis

Run this pass on every written or revised synopsis before delivery or scene development.
Run it for every option being offered, including fiction, synopsis-only requests and
unattended work. Reuse relevant evidence and recheck details affected by a change. For a
request that only displays existing prose, report its existing review status if relevant.

## Read the draft and mark what the story depends on

1. Read the actual synopsis in order, including the ending. Identify the facts, practical
   conditions and rules that let each central event happen. Check the place, period and
   season, travel and elapsed time, local language and customs, work and costs, and the
   institutional, legal, technical or physical steps the plot uses. Trace who could learn
   each consequential fact, when and from whom.
2. Match external details to evidence for the specific place, period and institution. Reuse
   current sources that answer the question and open additional sources for gaps. Prefer
   official documents for procedures and rules, local reporting or practitioners for lived
   details, and use the project's configured research lane. Open the source and read the
   relevant passage. A search snippet is a lead. For a legal or procedural detail, check the
   current rule or the version in force at the story date. If credible sources differ, record
   what each actually supports before using the detail.
3. Test fictional mechanics against the supplied rules, canon and ordinary constraints that
   still apply. Check resources, timing, information access and consequences. A wholly
   invented detail can stay fictional when its role and consistency are clear. Verify any
   real-world claim the invented world borrows.

## Correct and hand over the synopsis

4. Fix unsupported or impractical details in the synopsis itself. Preserve the user's fixed
   events, character choices and ending. Check the resulting timeline and consequences again,
   including every option or translation touched by the repair. If a fixed detail conflicts with
   the evidence, show the conflict and ask only when resolving it requires changing that detail.
5. Summarize what was confirmed, what changed and what remains uncertain. Link the source
   beside the finding it supports. Label reasonable inference, invented detail and unresolved
   facts as such. Record the findings with the existing synopsis or scenario when files are in
   scope. For a prose-only answer, a short findings paragraph is enough.
6. If a detail is unverified, first try a supported replacement or generalize it without losing
   the story's cause and effect. If the central event still depends on an unresolved claim,
   deliver a clearly labeled provisional synopsis with the exact gap. Unattended work saves
   that draft and stops before expanding it into scenes or generating media. If the core holds
   and only a minor detail remains open, carry the uncertainty forward and keep writing.

The author completes this pass. Scale the research to the importance of each detail.
Prop sheets, independent reviews and later production checks keep their own scope.
