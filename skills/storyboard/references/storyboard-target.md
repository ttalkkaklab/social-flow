# Local storyboard storage

Save every episode under `data/<channel>/episodes/<topic>/`.
The review lives at `storyboard/storyboard.html`, with `scenes.js` and its helper files.
No destination question or remote configuration is required.

Read the channel profile and character sheets from local files. Keep research,
candidate scenarios, approvals, review evidence, attachments, media and publication
logs in the episode directory. Preserve existing local assets when resuming work.

Use [storyboard-html-template.html](storyboard-html-template.html) and follow
[storyboard-design.md](storyboard-design.md). Deliver the local HTML path to the user.
Production and publishing continue from the same local files and update
`storyboard.md` to `approved`, `produced` or `published` as appropriate.
