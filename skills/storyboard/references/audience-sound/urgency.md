# 2. 기다림과 시간 압박

기다리는 사람이 얼마나 초조한지와 실제로 시간이 얼마나 촉박한지는 서로 다른 이야기다. 같은 간격으로 울리던 소리에 빈칸을 만들면 전자에, 빈칸을 점점 줄이면 후자에 어울린다. 상승음 끝을 무음으로 바꾸는 방법과 계속 오르는 듯한 착청도 참고할 만하다. [The Solos 효과음 시연][ableton] · [〈덩케르크〉 놀런 인터뷰][dunkirk] · [단편 관객 실험][suspense]

| 번호 | 상황 | 관객에게 들려줄 소리 | 넣고 뺄 자리 |
|---:|---|---|---|
| 011 | 답을 기다리는데 상대가 입을 열지 않는다 | 일정하게 세 번 울리는 건조한 합성 펄스 | 네 번째 자리를 비운다. 눈이 마주쳐도 소리를 다시 넣지 않아 기다리는 쪽의 민망한 시간을 살린다. |
| 012 | 선택지가 하나씩 사라진다 | 같은 음색의 짧은 펄스 사이를 차례로 좁힌다 | 남은 선택지 수가 줄 때만 간격을 바꾼다. 마지막 하나 앞에서는 연속음처럼 붙인다. |
| 013 | 끝나기 직전마다 시간이 연장된다 | 여러 옥타브의 상승음을 교대로 작아지고 커지게 겹친다 | 연장이 발표돼도 처음으로 돌리지 않는다. 끝없이 오르는 듯하다가 종료가 확정된 컷에서 전부 끊는다. |
| 014 | 두 장소에서 누가 먼저 끝낼지 모른다 | 한쪽에는 낮은 펄스, 다른 쪽에는 같은 속도의 높은 펄스 | 처음에는 각자 들려준다. 두 행동이 동시에 끝날 듯한 순간에만 같은 박에 포갠다. |
| 015 | 정답을 알지만 말할 차례가 오지 않는다 | 매번 끝이 잘리는 짧은 상승음 | 인물이 발언을 시도할 때마다 올리다 끊고 마침내 말을 시작할 때 첫 음절 앞에서 걷는다. |
| 016 | 남들은 느긋한데 한 사람만 조급하다 | 한 사람의 컷에서만 일정하게 떠는 중음 | 단체 컷에서는 멈추고 그 얼굴로 돌아올 때 같은 속도로 재개한다. 조급함의 주인을 정한다. |
| 017 | 결과 발표를 앞두고 시간이 늘어진 듯하다 | 한 음의 잔향을 점점 길게 늘인다 | 발표자가 명단을 펼치는 동안 울림을 끌고 간다. 이름을 말하기 직전에 끝내 첫 음절을 비운다. |
| 018 | 작은 실수가 누적돼 한꺼번에 수습해야 한다 | 짧은 합성 타격 두 종류를 서로 다른 간격으로 반복한다 | 실수 하나에는 한 종류만 쓴다. 두 문제가 겹친 뒤 두 패턴을 포개고 수습한 순서대로 뺀다. |
| 019 | 마감이 임박한 줄 알았는데 이미 지나갔다 | 빨라지던 연속음을 낮은 곳으로 급히 미끄러뜨린다 | 시각을 확인하는 컷까지 속도를 올린다. 늦었다는 사실을 읽었을 때 하강음 하나로 닫는다. |
| 020 | 숨 가쁜 추격 끝에 인물이 처음으로 멈춰 생각한다 | 촘촘한 펄스가 한 번 길게 이어지며 평평해지는 음 | 움직임이 멎자마자 자르지 않는다. 인물이 한곳을 응시할 때 펄스를 한 음으로 펴서 판단할 시간을 준다. |
