# Speech review and user corrections

There is no automatic human listening approval gate. Generate requested speech,
record provenance and continue with `not_reviewed`. Use [shot speech](shot-speech.md)
and [acting prompts](acting-prompts.md). A user's later correction invokes edit-speech
and affects only the selected lines and dependent media.

An explicit request for an adversarial improvement loop authorizes that review
within its scope. Report actual defects and measurements without inventing a pass.
Preserve the requested target and real spending limits. The loop's score does not
become a prerequisite for unrelated generation or assembly.

Character voice selection is a separate preference step: when creating a sheet,
play the three generated candidates and persist only the user's explicit selection.
A reviewer's score cannot substitute for that choice.
