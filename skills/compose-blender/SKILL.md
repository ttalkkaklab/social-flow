# Compose Blender

Own only `blender_composition`. Follow [the fixed workflow](../_shared/production-workflow.md)
for state, evidence, re-entry and stopping conditions. A completed board can re-enter here;
existing artifacts are inputs, not automatic passing evidence. Never skip prerequisites.

Require camera_review. Use [location assets](../storyboard/references/location-assets.md)
and the reviewed cut plan. This stage requires Blender even if the saved optional video
previz renderer is three.js. Missing Blender is a blocker; do not substitute another renderer.
Character, prop and background reference sheets are preparation assets, not these cut renders.

Build/reuse the shared set and bind each cut's camera, actors, gaze and prop states. Begin
blender_composition with the exact camera_review cut inventory. For each cut render through
location_manage action render. It returns compositionReceipt: the renderer-produced JSON
binding the shot ID, actual .blend and start image hashes. Register that receipt as text,
the actual source as blend, and its start frame as image. The output folder is generated by
the renderer: first register planned destinations, then rewind/re-begin this active stage
with actual returned paths before completion if needed; no downstream work exists yet.

Inspect all compositions in order against the reviewed camera plan. Fixes to the camera
plan return to review-camera. Complete only with current receipts and decodable renders.
Local animated previz remains optional; it does not replace these required still compositions.
Stop before AI image generation. Existing renders may be reused only with current bindings.
